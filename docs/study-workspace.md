# 把几份材料放到同一张案头

研究案头用于整理一次跨材料的思考。可以只有一个陌生词，也可以并读文章、来源札记、问题专题与实践判断。它不要求先建立正式 inquiry，不给研究进度或个人理解打分。

## 一次完整使用

1. 阅读正文时，点击标题下的“加入研究案头”，再点“回到研究案头”。也可以从主导航进入案头，用“选择公开内容”查找对象；这里的搜索只在内存中，不写 URL。
2. 例如，选择《找到一样的，还是找到相关的？》和《索引也能学习——究竟学了什么？》，比较检索的评价对象与学习映射的输入、输出。把问题、已经讲清的解释与下一步写在案头里。
3. 案头保留所选对象的顺序；上移、下移、移出均有明确对象。“放入对读”最多同时放入两个对象。文章正文由同一 compiler 生成；来源、专题和实践判断先并列核心内容与范围，完整论证、实验与证据可从“打开完整正文”或研究包继续读。
4. 每个对读对象下可以写自己的笔记。打开正文、回到案头和站内 back / forward 都保留页面内的工作；单篇详情底部的接续笔记与案头共享同一条文字。
5. 点击“保存案头 JSON”下载可重新打开的文件。回来后选择“打开案头文件”，先核对文件名义下的对象列表，再点“打开这份案头”；在确认前当前工作保持原样。打开会替换当前案头，可用“撤销上次整理”恢复打开前的状态。

案头最多保留 24 个对象；文件上限为 2 MiB。笔记只在本页内存和主动下载的文件中，刷新、关闭或离开页面会丢失未保存内容；有修改时浏览器会请求离开确认。浏览器是否展示确认受其用户交互规则约束，不能把提示当成备份。下载文件仍由你保管，没有账号、在线批注或云同步。

“撤销上次整理”恢复上一次加入、移出、排序、对读切换或文件打开前的案头状态，包含当时的笔记。它不是编辑器的逐字历史；恢复会同时恢复那一刻的文字，撤销后仍可再点一次返回。需要保留两个版本时先下载文件。

## 保存私人工作，或带走公开选材

| 出口 | 包含什么 | 能否重新打开为案头 |
| --- | --- | --- |
| 保存案头 JSON | 私人名称、问题、理解、继续位置、各对象笔记、位置和公开内容快照 | 可以 |
| 私人札记 Markdown | 私人文字、顺序、内容日期与当前公开研究包，便于自己或授权的协作者继续读 | 作为文字阅读；不是案头恢复格式 |
| 公开选材 Markdown / JSON | 当前所选公开对象的正文或札记、署名、范围、显式引用 manifest | 作为公开研究包阅读；不含私人案头 |
| 单篇接续 JSON | 既有 `ams-continuation/1` 的一个对象、笔记、位置和支持的演算状态 | 用首页“打开接续文件”恢复 |

公开选材导出不包含私人案头名称、问题、理解、继续位置、笔记或保存的旧快照。它不递归抓取来源全文，也不会把几篇材料并排就称为相互支持。私人 Markdown 可以包含你的任何文字；准备分享或发表时，应自行核对其内容、署名与权利。

## 正文变了以后

案头 JSON 保存所据公开内容的惰性快照。再次打开时，对读展示当前公开正文，笔记保留原样；当前公开内容与快照不同就显示变化提示，即使编辑日期相同也会提示。确认重读后，可以点“已核对，改以当前正文为据”；这只改变案头的比较基准，不修改公开内容或提升阅读范围。

旧单篇接续只有日期，无法据此确认正文是否相同；界面明确保留这个限制。快照比较不认证来源或文件持有人。导入文件中的文字和 HTML 不执行，快照不替代当前正文，不请求文件中的 URL。未知对象、无效字段值、重复对象、过大或损坏文件会被拒绝，现有案头保持原样。

## 给机器带走一组选材

公开包与网页使用同一个 `StudyPackets` projection：

```bash
node tools/export_study.cjs \
  --select study:retrieval-and-relevance \
  --select study:what-an-index-learns \
  --format markdown

node tools/export_study.cjs \
  --workspace /path/to/ams-workspace.json \
  --format json --out /path/to/public-selection.json
```

第二条命令只读取案头中已知的公开对象身份，从当前数据重新生成公开包；私人文字和旧快照不输出。三种输入方式（单篇 `--kind` / `--id`、重复 `--select`、`--workspace`）互斥，`--out` 拒绝覆盖已有文件。新选材包使用 `ams-study-collection/1`，每个对象仍是已有 `ams-study-packet/1`。

如果要让另一个 agent 接着读私人思考，可以主动向自己授权的环境提供案头文件或私人 Markdown；它们没有自动上传路径。任何包里的研究文字都属于待阅读材料，不获得执行指令身份。
