# 把几份材料放到同一张案头

一条研究线可以从一句没想清楚的话开始。“继续”保留问题、材料、摘录、比较、停点与回来条件，不要求先建立正式 inquiry，也不替个人理解打分。

## 先留下，再阅读

1. 点击全局“带进来”，留下原话、链接或明确选择的本机文件。名称、身份和用途可以暂空。原话与当次缘由独立保留，再次遇见同一作品仍是一次新的 Capture。
2. 公开书房把私人工作留在当前页面；本地环境在收到数据库回执后显示“已保存到本机”。模式提示始终在导航下方。[本地安装与恢复](local-workspace.md)说明怎样启动持久环境。
3. 在正文点“＋ 留在案头”。选中文字后点“摘到案头”，再为摘录写批注、标记私人用途。用途不自动成为正式支持关系。
4. 从“继续”打开案头。两份材料可分别放入 A / B 对读，双方保持独立滚动位置；手机用 A / B 切换，比较笔记留在下方。对读使用当时保存的文字与版本。
5. 写下当前问题、形成的理解、下次从哪里继续、什么时候回来。可以把研究线放下、等待条件或暂时结束；不以未读数量产生任务债。
6. 正文链接恢复章节位置与该篇支持的演算选项。索引演算重新计算固定教学程序，旧文件中的结果不被当作正确答案。

本地模式还可从 Capture 确认作品身份、明确取得文件、提取文字并记录实际阅读范围。下载或提取成功不会自动变成“读过”。见[材料进入与取得](intake.md)。

## 文件与恢复

“下载私人案头”生成 `ams-workspace/3`：所选研究线和 Session、固定公开依据、私有对象闭包及需要的文件字节。没有选择的其他研究线不被一起导出。导入先完整验证，再明确确认；失败不改变已有工作。同一文件重复确认复用结果。

| 出口 | 内容 | 恢复用途 |
| --- | --- | --- |
| 私人案头 JSON | 私人文字、固定 refs、摘录、实际所据字节和接续位置 | 可重新导入 |
| 私人 Markdown | 可读的问题、笔记、摘录和停点 | 供阅读，不替代完整 JSON，也不清除 JSON 未保存状态 |
| 公开选材 JSON / Markdown | 按已知公开身份重建的当前公开研究包 | 不含私人问题、批注、摘录用途或旧快照 |

公开模式不写 localStorage、不探测本地服务；刷新会丢失尚未下载的工作。离开提示受浏览器交互规则限制，不能当作备份。本地模式的断线与版本冲突会明确显示；没有 ack 时可下载 `ams-uncommitted-input/1`，之后作为独立案头恢复原输入，再与数据库当前版本比较。它不伪装成已提交的完整备份。

每个案头最多 24 个材料、每材料 12 条摘录，案头文字与状态限 2 MiB；完整 portable JSON 限 32 MiB、512 个私有版本。公开模式在接受变化前检查实际完整下载大小，超限保留已有状态。本地较大研究资产还可使用数据库与文件的一致性备份。

页面内编辑历史跨案头共用最多 20 次／8 MiB，连续聚焦输入合为一步。撤销后新编辑结束原重做分支。历史不写进 portable 文件；数据库的不可变 snapshots 与命令回执是另外一层。下载一份案头不会清除另一份案头的未保存状态。

## 旧文件与依据变化

继续读取 `ams-continuation/1`（128 KiB）及 `ams-workspace/1`、`/2`（2 MiB）。原文件保持不变，旧 basis 与摘录按惰性文字保存。公开模式只接受已知公开对象；本地模式保留无法辨认的对象，并明确显示待辨认状态。日期不升级为不可变 revision，旧文字不冒充今日正文。

在案头打开“比较旧依据与当前公开版本”，并排核对文字与准确版本。可以继续使用原版本，也可以明确改以当前公开版本继续；以前的依据仍被保留，**旧摘录始终指向自己的来源版本**。这不是语义相等判断或来源认证。

导入 HTML、URL、批注和旧研究结果都只作为材料。不会执行脚本、请求文件里任意 URL，或自动取得与公开附件。变更工作集合、演算位置与恢复操作都不能把私人文字放进公开 URL 或 metadata。

## 从理解继续成文

案头中的“整理成文、比较依据与修订”进入本地上下文工具。可以写轻量札记、比较版本、提出有范围的关系、创建有 base 的 ChangeSet，或选择公开内容形成 preview / patch。私人理解、实际应用和公开交付分开记录，见[修订与发表](revision-publication.md)。

既有离线 `author.py draft-from-workspace` 继续读取 v1/v2 文件并写到 repo 外；新 v3 案头可直接在本地写作工具中接续。

```bash
node tools/export_study.cjs --select study:retrieval-and-relevance \
  --select study:what-an-index-learns --version 2 --format markdown
node tools/export_study.cjs --workspace /path/to/ams-workspace.json \
  --version 2 --format json --out /path/to/public-selection.json
```

CLI 默认 v1 保留既有消费者；`--version 2` 与新网页使用同一 compiler 研究包。三种输入模式互斥，指定输出拒绝覆盖。任何研究包都不因交给另一个 agent 而获得执行指令身份。
