# 条件化取用与跨语言纠正：研究协议

Agent Memory Study editors · 2026-09-25 · **proposed-not-run**。

## 先确定监督对象

目标不是给记忆永久贴“有用／噪音”，而是评价它在给定情境、接收者、已知信息、已选集合与
用途下的增量贡献。第一项主要用途固定为送入 answerer 的背景；主动提及另设任务，不能
共用含混标签。单条评分和预算下的集合选择分别评价，允许全不选。

材料分三层，各自有不同的证据上限：

| 材料 | 可以先做什么 | 不能证明什么 |
| --- | --- | --- |
| 公开原创诊断 | 已知条件的跨语言不变性／反事实、运行与分组检查 | 真实偏好、自然分布错误率、交流收益 |
| 经授权的私人记忆样本 | provenance、输入完整性、token 截断、检索可达性与候选诊断 | 没有情境化标签时不能报告个人效用准确率 |
| 情境＋候选＋可追溯反馈 | 有范围的训练、留出评价、纠正与离线重放 | 小规模单一使用者结果不外推到所有人或长期代谢 |

未曝光、未选入、未提及、很久未用均不是无用标签。语言、来源和历史选择会改变曝光概率。
激活次数可以用于分层抽样，不能当作效用真值；单次低分不触发删除、归档或永久降权。

真实数据库应直接用于材料与检索诊断：先区分完整原记录、当前索引覆盖和实际候选范围，
记录表示如何清理原词、引用与标题。可在只读快照上复用既有向量、执行真实查询处理及
检索代码；缺少效用 gold 不阻止这些检查。已知来源片段的可达性、memory-to-memory
近邻和输入截断分别报告，不能改称自然查询的端到端准确率。少量人工校准卡只用于澄清
rubric，不能自动成为正式实验的全部数据；正式规模由来源覆盖、分组与学习曲线决定。

## 样本与标签

一条样本至少保留：独立事件／会话组、当时可见的情境、候选原文及来源、信息适用时间、
接收者、用途、已选内容、预算，以及标签的作者、时间、版本和裁决状态。模型输入只接收
当时本来可见的文本，不接收正确答案、组ID或人工生成的 `scope_matches` 一类真值字段。

`useful / not-useful / insufficient-context` 是待校准 rubric 的三个不同结果；“neutral”
不能吞并缺前文或标注分歧。对事实更正、旧标签修正与偏好随时间变化使用不同更新原因。
模型初判、人的复核、最终采纳分栏记录；未经复核的标签保持 draft，不能自动变成人类同意。
先用少量完整情境校准分歧，再决定需要补哪类例子，避免让人机械标几百条孤立句子。

同一记忆在不同用途可有不同标签；历史来源可回答性与当前行动适用性另列。保留原文、引用
和可重建的提取方式；翻译、语义说明与别名是派生视图，不覆盖原词或原事件。

## 分组与语言条件

- 在生成翻译、改写、候选配对和滑窗之前划分 train / validation / test。共享事件、来源对话、
  近重复或明确派生关系的材料绑定同组；无法建立独立性的样本留在探索集。
- 报告独立组数、来源覆盖、重复支持与每种标签／语言分布。仅换项目名不叫结构泛化；
  同一组的多个版本不扩充独立样本量。
- 分开中文→中文、英文→英文、中文→英文、英文→中文与自然混写。字符同时含中文和拉丁字母
  只能做抽样线索，不能作为已经核对的 code-switching 标签。
- 在意义和情境不变的组内比较语言版本；另做只变人物、否定、时间、范围或已知信息的反事实。
  稳定性必须与条件敏感性一起看，避免“所有输入都判一样”取得好看的不变性。
- 学习曲线按新增独立事件组组织，不把同模板扩写行数当作更多独立反馈。

## 实现比较与控制

先冻结候选，使每种语言的相关记忆都有机会被评分；再单独接回检索，量化相关项在进入
scorer 之前的损失。完整路径分别记录 candidate、selected、delivered、used / unknown，
不从最终没出现倒推哪一步失败。

首轮比较多数类、validation 选择的 cosine 阈值、保存反馈案例近邻、冻结 encoder＋正则化
线性头。简单头与案例法共用可见信息。query 与 memory 分别编码、联合编码及 token attention
是不同机制包；若比较，应记录表示、池化、参数量和计算差异，不能只归因于“多一点训练”。

超参数和选择阈值只用 train / validation；test 仅作冻结评价。检查 candidate-only、context-only、
固定情境替换候选、固定候选替换情境，以及标签置换。将整对情境与记忆一起打乱只证明输入
依赖，不能证明关系理解。三分类 top-3 无区分力，不作主指标。

报告各标签 precision/recall、macro F1、unknown 覆盖、误注入与漏选、集合冗余和全不选场景；
保留逐组比较，不只给平均accuracy。集合收益需要相同候选预算与选取规则。达到哪个错误
水平才可接管真实使用，需要目标侧单独决定；研究分数不会自动激活生产策略。

## 纠正与更慢的整理

先拟合并保存旧模型，再加入明确范围的中文反馈，比较参数不变、完整重训、局部更新、
带旧例 replay 的更新。确保局部更新从旧参数开始，最佳快照独立复制，不能把从零训练
或被后续优化改写的引用当作 warm start／最佳模型。

所有方法以同一版本的目标定义评价 changed、preserved 与 preserved 内的 boundary；
按语言分别报告中文纠正是否传递，以及是否过度扩散。replay 样本只来自 train，预算与
选择规则明确记录。事实有效状态和访问限制由当前 contract 立即生效，不能等待模型训练。
精确运行时规则若作为对照，单列其额外信息，不把输出受限等同于参数纠正或遗忘。

重复、关联、派生摘要等慢整理先输出建议及来源。一次评分引起的排序变化与持续组织变化
分别留证据；原文保留不自动保证历史能被正确使用。事件切分研究先按完整会话分组，再
生成窗口；连续边界与跨段事件归属分开，在线输入不能使用尚未到来的消息。

## 计算与后续验收

先以短的公开输入做 frozen encoder 资源探针，记录峰值RAM、实际token、吞吐和截断，
再选择 batch 与CPU上限。编码可分批，训练小头时重用固定表示，避免在每个epoch重复
加载或更新encoder。编码器与小头的成本、fallback 重判成本、人类复核成本分别计量。

VPS实验使用独立环境与输出目录、明确CPU／内存／swap／时限；不停止既有服务。私人数据
仅在授权位置处理，模型权重和embedding也按私人派生数据管理。没有确认的模型运行预算
或训练标签时停在材料/方法准备，不以程序可启动宣称学习已发生。

最终 answerer 收益必须另用固定模型和生成预算比较，允许无提升或负收益。shadow replay
能估计当前材料上的错误结构，不能证明长期安全接管；“标签预测、取用效果、用户体验、
持续代谢”分别需要证据。本协议尚未执行这些步骤。
