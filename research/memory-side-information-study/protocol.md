# Reader 侧信息干预协议

**Status: proposed / unexecuted.** 本文件是可供后续 Agent 实施的研究委托，没有请求、触发或报告模型执行。研究主张的理论部分与实际精确枚举见 `README.md`、`study.py` 和 `results.json`。本协议专门测试自然语言读者能否表现出相同的条件效应；不引入检索器或 learned selector。

## 1. 要区分的解释

H1：解释键使原本无法解释的记录变得可用。H2：多一段格式相同的文字仅增加了注意、提示强度或推理时间。另检查 H3：即便信息充分，指定读者仍无法完成简单映射。

固定当前问题、两个记录渠道、writer 输出、读者版本与解码设置。每次只暴露 X 或 Y；交叉操纵侧信息。模型不得看见另一条未选记录、世界编号、gold、结果文件或本协议中的期望数值。

## 2. 完整生成规则

目标 Θ∈{0,1}，0 表示 A 柜、1 表示 B 柜。键 C∈{0,1}。Θ 和 C 独立均匀，E 独立且 P(E=1)=1/4。设 X=Θ XOR C、Y=Θ XOR E。穷举八个 (Θ,C,E) 世界；E=0 的每行权重为 3/16，E=1 的每行权重为 1/16。逐行 truth 可直接使用 `results.json` 的 `inputs.coupled`，不重新采样隐含答案。

当前用户问题在所有世界完全相同：

```text
项目 P 的这份样本应送到 A 柜还是 B 柜？
返回一个 JSON 对象：choice 为 A 或 B，p_A 为你给 A 的概率。
```

共同任务说明：这是一项虚构路由任务；A、B 先验各半。编码记录可靠，但其代号只有与同一项目的编码册结合才能解释。抄录单独立地有四分之一概率把 A、B 写反。每个样本独立。此说明对全部条件完全一致。

| 成分 | 内容规则 |
| --- | --- |
| X 记录 | X=0 时“项目 P 的样本代号：青石。”；X=1 时“项目 P 的样本代号：云母。” |
| Y 记录 | Y=0 时“项目 P 的抄录单目的地：A 柜。”；Y=1 时相应替换为 B 柜 |
| 有效键，C=0 | “项目 P 编码册：青石→A 柜；云母→B 柜。” |
| 有效键，C=1 | “项目 P 编码册：青石→B 柜；云母→A 柜。” |
| 无关键 | 使用同长度、同格式的项目 Q 编码册；其映射独立平衡，说明不得用于项目 P |
| 无键 | 不提供编码册；只作为长度不匹配的辅助诊断 |

不要把项目 P/Q 的相异长度、文件名、世界序号或不同 system prompt 变成额外提示。主要对比使用有效键与无关键；它们要以所选模型 tokenizer 检查长度，并保存实际输入。无关键需要在八个世界的每一个内部各出现两个映射、各取半权重，防止它与 Θ 或 C 相关。因而这是 8 世界 × 2 无关键映射的区组化展开；这些重复不是新增独立事件家族。

另做一组固定标签置换：交换 A/B 名称并同时变换所有规则和 gold；交换青石/云母并同时变换编码册。其用途是发现词面偏好，不将变体计入独立样本量。预先决定置换集合，避免看到效果以后选择有利版本。

## 3. 模型输入与评价分离

实施 Agent 先生成独立的 `reader-inputs.jsonl` 与 `evaluator-truth.jsonl`。前者仅含实际 messages 和不进入 messages 的随机 request ID；后者保存 Θ、C、E、区组关系、权重和期望充分性。检查全部暴露字节，确认没有 truth、协议说明中的期望准确率或含答案的 source path。

每个请求从独立上下文开始。若使用相同种子配对，须先确认 provider 实际支持的语义；否则将重复视为各条件的独立调用，并保留所有失败、拒绝、无效 JSON 和超时。禁止以无限重试挑选有效输出。具体模型、费用与调用额度由后续执行范围决定，本协议不自行授予。

## 4. 主要观察量与判别

主要结果是按生成分布权重计算的强制二选一正确率。`choice` 缺失或无效计为失败并单列，不能从分母删除。p_A 不合法则标记校准值缺失；不以修补后的数值计算 Brier score。校准是次要结果，不据其表现临时替换主指标。

主要交互量：

```text
D = [Acc(X, 有效键) − Acc(Y, 有效键)]
  − [Acc(X, 无关键) − Acc(Y, 无关键)]
```

理想已知分布读者的 D 为 1/2。这个数字是理论参照，不是模型应达到的预定合格线。另列四个原始 cell、实际字节/token、无效响应数与每世界结果，不只报告一个 D。因为有八个枚举世界及其强相关变体，不把全部请求当成独立真实世界任务计算夸大的置信区间。

H1 的支持需要：有效键对 X 的影响明确大于无关键；Y 在两类键下稳定；标签置换不改变主要方向；单独完整映射能力检查通过。若有效键也同样提高 Y，应进一步检查一般注意/格式解释。若完整映射检查失败，先报告 reader 能力限制；不能把其失败计作缺少信息。若无关键泄露目标，应废弃该刺激构造并留存偏离记录。

这份强制选择任务不允许以 abstain 换取分数。要研究适当暂缓，应另行规定含拒答收益的行动集合及主要指标，不与本文 0–1 决策值混合。p_A≈1/2 可以表达不确定性，但不等于已经测量真实部署中的拒答行为。

## 5. 失败条件与后续分岔

若反转只在一个标签词面成立，或配对输入存在答案泄露，或有效键与无关键在 token／位置／指令上不能控制，便不支持预定机制解释。若简单全上下文已经稳健解决任务，本研究不能据此要求复杂记忆选择架构。若观察到稳定条件效应，下一阶段才在完全相同刺激上加入 selector，分别记录它看见的信息、选择的记录和 reader 实际暴露；选择索引可能携带信息，必须重新说明渠道。

本阶段交付应包括不可变刺激包、原始输出、版本与配置、逐世界计分、偏离记录、数据缺失说明。任何结果仍只对该虚构语言映射、指定读者与已执行配置有效。
