# Pre-registration deviations and holds

## Six-stratum selector replaced before controller output

The first independent design proposed one exact answerable/abstention Medium
class in each domain-by-type stratum. Running that exact selector on the locked
public maps produced three eligible classes, all `web x procedure`, and zero in
the other five strata. No controller output existed.

The revised rule selects every exact pair-eligible class in the complete public
pool. This preserves strong within-family evidence matching and narrows external
scope. It does not loosen equality to unordered membership, manually pair
questions, or add non-paired breadth.

## Full trajectory resolution not performed

The complete public trajectory file was not retained after an earlier streamed
Small extraction. Because the exact controller runtime gate was already closed,
the 1.20 GB file was not reacquired merely to execute a downstream gate that
could not authorize controller work. `raw/source_lock.json` records its expected
official hash but marks it unobserved in this audit.

## Exact controller runtime held

The intended Codex CLI `0.117.0-darwin-arm64` package was available from an
existing package cache and unpacked without network access. Its candidate binary
could not produce a version receipt and exited 137. Read-only Gatekeeper
assessment returned `CSSMERR_TP_CERT_REVOKED`; its embedded signature structure
still satisfied the designated requirement. No trust, quarantine, or Gatekeeper
bypass was attempted. The temporary unpack was removed from the test location.

Current CLI versions were not substituted. Therefore the planned 66-job
controller phase remains `HOLD`, with zero jobs executed.

The original terminal logs were not retained as a publication-grade raw receipt.
`raw/runtime_attestation.json` therefore labels these fields as an
author-recorded local preflight observation that the artifact does not replay.
It is used only to record failure of the preregistered no-bypass local signing-
trust gate; it is not presented as an independently reproducible runtime result,
malware finding, or claim about another Codex release.
