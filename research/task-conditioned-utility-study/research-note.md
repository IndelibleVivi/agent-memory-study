# 测到记忆帮了忙以后，仍然不知道该不该留下它

## 研究位置与证据身份

AMS 的 `conditional-information-and-use` 已经区分条件增量、双源交互、真实送达、消费者输出和理想信息单调性。这篇札记沿着那条研究继续走：当配对调用确实产生了结果，如何避免把局部测量升级成一个尚未得到支持的保留政策？

本轮重新计算的是 [Conditional Memory Utility 官方公开结果](https://github.com/ChihHsuan-Yang/AAMAS2027-ConditionalMemory/tree/386ac65a8b5fc46414abdd2755375f2a52d4d3b8)。没有运行新的 LLM。输入、源码版本、校验值、执行命令与数值输出见同目录 README 和 JSON。论文提出的条件化效用、机会条件化和 sign-flip 警告归作者；本轮完成独立复算，并增加下面的代数分析与解释。

## 一、先把测量里的人口还原出来

公开切片给出 2,599 条 replicate rows，合并为 1,157 个不同 memory–task cells。同一 cell 的已有调用结果相同。139 个 answer-bearing cells 中，有 50 个从错变对、2 个从对变错、73 个持续错误、14 个持续正确。这个设计中，只存在 16 个可以观察到“记忆破坏原本正确回答”的机会。

这解释了两个看上去都正确、含义却相差很远的比例：

\[
P(\text{hurt})=2/139\approx 1.44\%,\qquad
P(\text{hurt}\mid \text{baseline correct})=2/16=12.5\%.
\]

第一项描述设计中的总体频率。第二项描述已有正确结果被破坏的机会率。不能把第一项拿去证明“记忆几乎没有风险”，也不能把第二项当作真实部署的普遍损害概率。

本轮另做三种聚类重抽样。Bearing 条件损害率的 task-clustered 百分位区间约为 `[0,0.5503]`，memory-clustered 约为 `[0,0.3077]`，episode-clustered 约为 `[0,0.3636]`。这些是描述性 bootstrap 敏感性检查，各自依赖一种聚类假设；它们不能同时解决交叉依赖或选择偏差。Task bootstrap 的 10,000 次抽样中，18 次没有任何 baseline-correct cell，条件率没有定义，代码明确丢弃并记录。区间上界的大幅差异本身就提醒我们：两次伤害事件不足以支持精确的稳定性主张。

## 二、较强的基础能力会改变记忆的机会结构

对二元任务，令 `Y0` 是不注入记忆时的正确性，`Y1` 是注入后的正确性。定义：

\[
p=P(Y_0=1),\quad h=P(Y_1=1\mid Y_0=0),\quad e=P(Y_1=0\mid Y_0=1).
\]

按四种转移展开：

\[
\mathbb E[Y_1-Y_0]
=P(Y_0=0,Y_1=1)-P(Y_0=1,Y_1=0)
=(1-p)h-pe.
\]

这是恒等式。作者已讨论机会条件化，本轮的额外步骤是把它用于一个明确标注为假想的标准化：保持 `h,e` 不变，只改变不使用记忆时的正确率 `p`。

若一次调用的成本换算成相同 reward 单位为 `c`，固定这些假设下的有益条件是：

\[
(1-p)h-pe>c.
\]

当 `h+e>0`，可写成：

\[
p<\frac{h-c}{h+e}.
\]

如果 `h≤c`，即使所有 baseline 都错，期望增益也不足以抵偿成本。若 `e=0,c=0`，随着 `p` 增大，帮助空间趋近零，仍不必产生负效用。要出现负值，需要破坏正确结果的通道或正成本。

把本轮复算的 bearing 点估计代入：`h=50/123`，`e=2/16`，零成本阈值约 `0.7648`。在假想 `p=0.8` 下，净变化约 `−0.0187`。这个数值**没有预测某个更强模型会受害**：升级模型通常同时改变 `h,e`；真实任务变了，条件子群也会变。它只是证明，一个在低 baseline 正确率上有正平均收益的注入规则，不能仅凭旧平均收益获得跨能力水平的保证。

第二 reader 的现成切片也值得分解。严格取两个 reader 共有的 275 个 cells，gpt-oss 的 baseline 正确率为 `20/275`，Gemma 为 `10/275`；平均效用分别为 `0.2182` 与 `0.3164`。较大的效用增量没有自动证明 reader 的无记忆能力更强。这两个量回答不同问题。Reader 差 `+0.09818` 的 task-clustered 区间复算约 `[+0.02362,+0.17347]`，与官方结果一致。

对 AMS 的直接要求因此很具体：比较新旧模型时，同时报告无记忆能力、救回率、破坏率和两边共有的样本。不能只携带一个历史平均 memory gain。

## 三、不能估计一个方差份额，不等于不能检查加性限制

论文提醒我们，记忆对一些任务为正、对另一些任务为负，并不能证明 memory×task 交互。假如

\[
d_{mt}=a_m+b_t,
\]

同一记忆也会随着任务项 `b_t` 的变化而跨过零。

本轮把一个更窄的问题直接作用于公开数值：这些已经保存的 `d_mt` 能否**精确**写成这种加性形式？它不需要先估计一个随机效应方差份额。

设已观测 memory–task 配对构成二部图 `G=(M∪T,E)`。每条边上观测一个值 `d_mt`。如果存在 `a_m,b_t`，任意四环都满足：

\[
d_{m_1t_1}-d_{m_1t_2}-d_{m_2t_1}+d_{m_2t_2}=0.
\]

更一般地，每条偶环的交替和必须为零。反向也成立：在每个连通分量选择一个顶点势为零，沿一棵生成树逐边解出其余势；每条非树边能与已有势一致，恰好要求相应基本环的交替和为零。因此，图上所有偶环均为零，是精确加性可表示的充要条件。只检查四环可以发现反例，但无法覆盖所有没有四环的稀疏图。

若图有 `c` 个连通分量，含一个 memory 指示项和一个 task 指示项的设计矩阵秩为 `|M|+|T|−c`。其独立环限制数为：

\[
|E|-|M|-|T|+c.
\]

在这份记录上，`|E|=1157, |M|=60, |T|=218, c=2`，故 rank 为 276，独立环限制空间维数为 881。70,638 个枚举四环中，20,016 个交替和不为零。一个来自 RANDOM stratum 的见证如下；完整 IDs 保存在结果 JSON：

| | Task 1 | Task 2 |
| --- | ---: | ---: |
| Memory 1 | 0 | 0 |
| Memory 2 | 0 | 1 |

四个 cells 的无记忆结果全为错误；交替和为 1。它已经足以排除精确 `a_m+b_t` 表示。

这个结果的上限同样清楚。目标 memory 的插入位置随 cell 变化；不同内容也有不同长度；没有一个排除了这些路径的语义 placebo。即使所有非加性都来自位置扰动，这个表仍然可能出现。因此它**不识别语义交互、不估计总体交互比例，也不反驳作者对其特定方差模型不可识别性的说明**。70,638 个环大量重叠，不能变成 70,638 个独立实验。二元结果下非加性也不令人惊讶；其价值在于让“还能问哪种数学问题”与“仍不能做哪种因果解释”分开。

代码中的两个有限控制检查这一点：纯加性但含正负翻转的矩阵，其环和全为零；给一条边加上模拟位置扰动后，环和非零。后者没有任何语义记忆机制，却足以通过所谓“检测交互”的粗糙判据。

## 四、固定总长度复现了什么

独立运行官方 fixed-context 脚本之后，结果与论文的 cell counts 和效果一致。它增强了一条有边界的判断：这个 writer、这些 factual questions、这些被保留的 cells 上，Raw 的优势不能单靠总输入长度差解释。

这里的固定长度结果与置信区间来自实际执行作者的 `x2_analyze_fixed_context.py`，并非 AMS 另写了一份独立 estimator。相对地，本目录 `results.json` 的主效应、reader 配对差和条件损害率区间由 AMS 的 `reanalyze.py` 独立计算。离线 `check_saved.py` 只校验保存结果的身份、代数关系与区间边界，不从缺失的原始行重新抽样。

作者所称 query-blind writer 也需要分成两个证据层。固定源码的 `_LLMWriter._call` 只把 `segment.text` 传给 prompt；写入阶段使用 `none:write_pass`，fixed-context runner 读取事先建立的 representations。实际执行的 writer signature check 通过，保存行中的 summary/structured prompt version 与该版本 loader 计算的标准化 hash 相符。但 2,216 条 fixed-context rows 的原始 inference `code_sha` 都是 `unknown`。这些核对支持源码的信息边界，并没有认证每一次历史推理确实运行了此 commit。prompt 文件原始字节 hash 与 loader 标准化 hash 也不是同一个对象，二者在 receipt 中分别保存。

它仍没有使两个系统面临同一种真实资源分配问题。对压缩出来的空位填入无关 filler，会固定 prompt 长度；在实际工作里，空位可能用于另一条相关证据、当前任务信息或推理预算。比较“把空位填满无关材料”和“把空位交给最佳替代用途”，是两种不同的反事实。

这是对评价合同的解释，不是本轮已经发现了一个更优压缩器。只有确实存在有价值的替代信息、预算约束使材料竞争，而且释放出的容量能够交给该用途，机会成本才会形成实际收益。把输入 token 直接换成内部推理预算还需要额外的部署资源模型，不能由等长 prompt 实验自动推出。若不存在这样的替代用途，或压缩恰好丢失了决定答案的细节，Raw 在这里的优势依然是应当保留的负面证据。

AMS 已有 equal-budget/raw-versus-compact 构造允许材料在预算下相互挤出。外部论文提供的固定总长度复现与这一机制并不矛盾。一个检查压缩是否保住当前必要内容，另一个检查受预算约束时最终送达什么。二者都不能直接给出长期 retention policy 的收益。

## 五、从 exposure effect 到 retention value，缺的正是未来政策

注入某个内容的局部配对结果，可以写成 `Δ(m,q | F,p,reader)`。保留则是一项更早的动作，会改变以后有哪些内容可查、检索成本、选择竞争、更新机会，以及有时用户和 Agent 接下来会做什么。

最简单的单步桥梁已经需要额外假设。若未来任务来自已指定分布 `D`，曝光规则为 `g(q)∈{0,1}`，存储不会改变其他记忆，且每项收益与成本能相加，那么：

\[
V_{D,g}(m)=\mathbb E_{q\sim D}[g(q)\Delta(m,q)]-c_{write}-c_{store}-\mathbb E_{q\sim D}[g(q)c_{read}(q)].
\]

这条表达式明确依赖 `D` 与 `g`。任务条件性允许我们构造一个相对于已知分布的标量期望价值；它并不禁止所有标量。错误发生在把这个条件化标量宣称为记忆固有、跨任务分布、跨 reader 的永久重要性。

若用户的未来关注发生变化，或保留动作改变以后检索集合，上式可能不足。动态定义应比较两条完整政策下的返回，并说明未来任务到底是外生固定还是行动造成的结果。仅有本轮的一次性配对输出，无法识别这些政策效应。

这也解释了为什么 answer-bearing screen 可以是好的测量工具，却不能直接成为保留器。测量时研究者知道 gold，可以挑出足以检查机制的配对；保留发生在未知问题出现之前。把 screen 的选择收益直接写入 retention policy，会跨过这条信息边界。

## 六、对两篇学习论文的具体追问

### MemAgent 的 downstream success 仍需反事实

该论文的 End reward 把后续命中频次与命中任务的成功率组合起来。公式可简记为：

\[
r_{end}=\tfrac12\min(1,n/H)+\tfrac12 s/n,
\]

在 `n=0` 时第二项用保护分母；原文具体定义见 Eq. 2。[MemAgent v1](https://arxiv.org/html/2609.32521v1)

下面是 AMS 的独立反例，而非该论文的观测。取 `H=5`。条目 A 在五道原本就会回答的题里被检索，全部成功，得分为 1，但条件增量全为零。条目 B 在一道原本会失败的题里使回答成功，得分为 0.6，却有一次真实改善。更强的不可识别性来自两个世界：两边的检索和有记忆成功记录完全相同，无记忆结果却不同；公式在两个世界给出同一个 reward，因果效应不同。

这种 reward 可以是实用的监督启发式，整个系统也可能因此更好。它无法仅凭自身证明哪一次存储造成后续成功。AMS 应把“反馈可训练”与“贡献已归因”分别记录。将可训练启发式误叫因果标签，会使接下来的实验错误地奖励本来就容易的任务。

### UMA 的共享学习信号连接两阶段，但没有解释每次写操作

UMA 把任务盲记忆轨迹分叉到多道未来问题，并用下游平均结果监督上游记忆维护。这个跨阶段信号比只看一条写入是否格式正确更接近未来使用。但平均奖励分给整段 session，仍不能指出某个 Update 或 Delete 的独立贡献。其 reader 还可访问 raw context；关闭该通道的系统变化，应与“结构化记忆本身保存了什么”分别分析。[UMA](https://aclanthology.org/2026.emnlp-main.1299.pdf)

从这两条机制继续 AMS，值得坚持的问题是：**反馈需要多精确的因果含义，才能学出在任务分布改变后仍值得信任的保留与调用规则？** 未必每次 CRUD 都需要昂贵的反事实，但必须知道监督信号把什么捷径当成了成功。

## 可直接执行的下一项研究协议（本轮未运行）

用一组自然来源制作 query-blind memories，固定 reader 和候选库，把检索阶段的 policy selection 与 writer retention 分开。每个未来任务至少运行四臂：不注入、真实记忆、等长无关内容、同位置的任务相关替代证据；位置随机化在每个任务内配对。记录两边 correctness 与成本，保留 baseline-correct stratum 的足够样本。

训练调用门时使用一批任务，评估时分别改变任务分布和 reader；选择行为不能读取 gold 或事后 Delta。比较全量调用、从不调用、只按成功次数学习、按配对增量学习。对 storage 的价值另建未来 reuse horizon，持久状态在两臂真正分叉，记录对其他条目的挤出。接受结果包括“简单 no-memory 已赢”“训练 gate 只学会了数据集类型”和“效应仅在同一 reader 上稳定”。

上述协议目前只是候选设计。本轮完成的是公开结果重分析、数学诊断和明确的不可识别性反例。
