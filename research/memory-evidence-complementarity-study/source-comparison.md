# Source comparison: what is established, and what this study adds

整理日期：2026-11-05 · Cove · AI-assisted research
状态：原始文献比较。除另有明确标记的 InMind 固定版本静态审计外，本文件不声明执行了上游代码或复现了论文分数。

## 比较问题

“互补证据”可以指至少四种不同对象：相似度较低的条目、带来新增事实的条目、给定读者下提高答案概率的集合，以及在规定任务语义下完整覆盖一条充分路径的集合。这些对象可以相关，但不能互相替代。

本研究的 [精确脚本](study.py) 只直接观察作者定义的集合效用或充分性；不会把 embedding 距离、LLM 的新增信息评分、gold-answer likelihood 或引用出现，当成这个函数的现成测量。

| 来源 | 实际研究对象 | 作者提供的证据 | 本研究的延伸或边界 |
| --- | --- | --- | --- |
| AgentMemRec | 请求、agent state、候选、ranker 与预算内 slate；给定 gold evidence 的完整性 | 两个长期记忆 benchmark 的系统比较，完整 slate 条件分析，高 `κ` 与 near-miss 分析 | 将单一 gold set 推进到替代支持族；用完全相同的低阶效用 transcript 区分信息不足与学习失败 |
| SG²RAG | 基于新增语义信息的文档图与 query-seeded propagation | 多跳 QA，同候选对、图边和传播方式的对照与消融 | 语义边可能携带高阶任务线索，不能被当作“只知道两条效用”；新增信息也不是任务边际收益 |
| OptiSet | 候选证据集合的生成、完整集合效用标签及训练 | 多个 QA 数据集、模块消融与不同训练目标比较 | whole-set scoring 越过低阶接口，但价值仍依赖生成器、候选提案及训练标签；不是读者无关的最优证据标注 |
| InMind | 隐含关联下主动回忆并应用历史的记忆系统评估 | 基准结果、直接注入对照与评审人工审计 | 区分规范上的 recall-and-warning、独立评审分数与真实因果使用；不把 nominal recall 自动当准确率上界 |
| Nemhauser–Wolsey–Fisher | 单调次模集合函数在基数约束下的近似优化 | 形式定理与最坏情形界 | 互补支持函数可以违反次模条件；不能只凭 greedy 形式借用近似保证 |

## 1. Agent Memory as Recommendation

原始版本：[arXiv:2610.34673v1](https://arxiv.org/html/2610.34673v1)。主要阅读范围：§§3–4、§7 及相应实验设计。以下是论文阅读，不是源码行为确认。

### 论文实际说了什么

§3.1 的请求为 `x=(q,t_q)` together with the agent's state。代价是渲染后的 token 数，奖励来自读者回答及其评判。它已经允许 slate reward 是集合函数；不能将本研究的集合视角声称为对此文的根本纠正。

§3.3 定义 `r_pool`、`r_rank`、`r_slate`，并使用完整与不完整 slate 的平均奖励 `a_c,a_i` 写出全概率分解。对于逐条排序的归约，论文列出额外假设：给定问题时，完整/不完整 slate 的平均收益不依赖具体组合；单位代价可加；各单位属于 gold set 的事件在选择器信念下独立。它也指出，组合收益和相关证据会使这个归约的前提失效。

§7 已经研究高 `κ` 的组合困难与 near-miss filler。论文对负收益作了必要的限定：增添条目后表现下降，可以用负的单条价值解释，单凭该现象不足以证明非可加性。因此不能把“高阶组合可能失败”或“加入内容会伤害回答”重新包装为本轮首先发现的问题。

### 作者报告结果与可解释范围

论文在其固定模型、任务与预算协议下报告 slate 完整性与正确率的关系，以及更高 `κ` 条件下的表现变化。它们支持这一研究场景中的组合问题。它们不自动识别每个问题的因果用材，也不证明全部未标注替代支持已经被排除。完整/不完整集合中的问题组成可以随策略变化，条件均值并不是天然可迁移的阶段参数。

### 本研究新增的精确问题

固定 `q,C,U,b` 后，让所有 `|S|≤2` 的效用观测在不同三元支持世界中相同。这比“某个 ranker 在高 `κ` 上下降”更窄：它规定了怎样的信息输入不足以区分世界。另将 `G⊆S` 换成“存在 `T∈K` 使 `T⊆S`”，容纳多个替代的最小充分集合。新加的预算可行事件形成嵌套恒等式，但仍不是因果分解。

## 2. SG²RAG

原始版本：[arXiv:2610.15285v1](https://arxiv.org/html/2610.15285v1)。主要阅读范围：语义增益评估与构图、controlled Personalized PageRank、§5 对照和有效性分析、结论。

### 机制

系统先在语义相近的候选对中评估一段材料相对另一段增加的信息。原始评价是有方向的；构图把方向性评估聚合成对称连接。在线检索以查询相关节点为种子进行受控图传播。构图的候选对并不是整个语料的所有可能组合，图所能访问的关系受离线近邻选择约束。

这个机制区别于仅仅奖励“不相似”的 MMR 式多样性。新增信息可以与当前已有内容高度相似，却填补关键连接；不相似内容也可能完全无关。论文的消融在其设置下比较了这些设计选择，而不是为任意任务证明一种普适排序关系。

### 作者的有效性检查是什么

论文把同一个问题的 supporting-document membership 用作事后分析代理，比较 Gold–Gold、Gold–Distractor、Distractor–Distractor 的语义增益分布，并在同一组候选对上与 cosine similarity 比较。作者明确说明这不是对一个潜在真实效用函数的理论验证，gold membership 也不用于构图。

因此，本研究采用这个检查作为“代理与证据关系有关”的作者报告证据，而不把它重写成 `F(S∪{e})−F(S)` 的直接观测。具有新增事实的文档，未必是当前任务所需；两个都被标为 supporting 的文档，也不自动形成完整路径。

### 与低阶接口的关系

本文的下界**不适用于仅凭拓扑被称为 pairwise 的任意图**。语义评估模型可能在读两个节点时识别桥接结构，边权也可能反映训练知识或额外上下文。应先声明模型可见输入，并问这些输入是否在隐藏支持世界间相同。若不同，它已获得下界明确排除的额外信息。

可执行的后续对照是同候选池、同读者、同预算下，比较真实语义边、打乱的语义边和仅由低阶任务效用构造的边；还需区分查询之前的图与查询条件化图。SG²RAG 的结论已经把 query-aware refinement 和 candidate expansion 列为后续方向，本轮不把这两点当作其作者遗漏的问题。

## 3. OptiSet

原始来源：[ACL Anthology](https://aclanthology.org/2026.findings-emnlp.339/)，[官方 PDF](https://aclanthology.org/2026.findings-emnlp.339.pdf)，DOI `10.18653/2026.findings-emnlp.339`。重点阅读 §§3.1–3.3，实验及相应消融。本文未运行项目代码。

### 集合构造、训练输入与效用

§3.1 的 expand-then-refine 先扩充查询覆盖，再构建和重新选择证据集合。§3.2 多次采样产生同一个问题的不同候选集合；训练数据构造使用可选的 gold answer。该信息必须标为训练输入，不能无依据地当作推理时答案泄漏。

§3.2.2 的 `PPL` 是固定生成器逐 token 对 gold answer 的条件概率所对应的 perplexity；`H=log(PPL)` 因而是平均负对数概率。论文将它称作 entropy，但它与对真值随机变量分布求期望的 Shannon 条件熵不是同一个数学对象。

论文进一步使用无证据基线 `H_0`，计算 `ΔH=H_p−H_0`，以控制生成器内部知识导致低 PPL 却没有增量帮助的情况，再构造偏好标签。§3.3 使用集合选择与 list-wise 目标训练。这表明它确实对完整集合分配效用，而非仅靠独立条目分数。

### 对 AMS 的意义与限制

完整集合评估允许三条支持一起显露收益，因此可作为低阶界之外的对照。但它只能比较实际被提案、采样或搜索到的集合；候选提案遗漏的支持不能由精细评分补回。基线作差也没有消除所有读者依赖：模型版本、已有知识、prompt 和上下文可能同时改变 `H_0,H_p` 及集合之间的顺序。

这与 [侧信息文章](../../study/entries/memory-value-side-information.md) 的关联是本研究的推论：效用标签的迁移需要明确条件，而不能从“已扣除无证据基线”直接推出。该推论不等于对 OptiSet 论文实验的否定，也没有经过本轮模型执行检验。

## 4. InMind：谓词、评审与来源接触应分开

原始论文：[arXiv:2607.24368v1](https://arxiv.org/html/2607.24368v1)。本轮另有 [固定版本源码审计](../inmind-evaluation-source-audit/README.md)，锁定 [`5a2ab2686d3d5b832575f0288d41ecc93eab358b`](https://github.com/imlrz/InMind/tree/5a2ab2686d3d5b832575f0288d41ecc93eab358b)，文件哈希见该目录 source lock。

论文考察当前查询没有直接提示某条历史时，系统能否回忆并应用相关约束。它给出了直接注入目标记忆的对照，这有助于区分检索暴露与下游应用，但没有自动排除所有读者、提示和评审因素。

规范上的成功应用要求回忆相关上下文并给出提醒，因此真实的合取事件不能比其中的回忆事件更常发生。实际测量却由不同的自动评审输入产生：应用评审读取回答，目标召回评审看检索材料并排除生成回答。论文附录 14.2 已审计并解释两种评审的误差；本轮不是首次发现此问题。

表 1 的全部配置中，最高应用分数为 Naive RAG 的大 embedding 配置的 16.0%；若只看六个命名记忆系统，最高为 MemoryOS 的 14.4%。直接目标注入对照为 84%。比较时必须说明集合，不能把 14.4% 写成所有配置的最高值。作者人工检查的 100 个记录中，recall 评审一致率为 97%，application 为 85%，后者含 15 个 false positives。它们不是本轮重评得到的结果。

本轮固定源码静态观察还确认，文档要求冻结同一记忆状态再比较不同查询；不能仅根据 prose 顺序推断 naive query 的写回污染了后续查询。静态文档要求也不等于所有 adapter 的状态隔离都已由本轮实跑证实。

对本文的作用是限定完整性上界的适用范围：只有证明证据必要性、支持标注覆盖、读者背景和测量一致性之后，才可从完整支持推到任务成功上界。一个 noisy aggregate recall score 没有这种自动资格。更详细的后续配对盲审协议留在审计文件，避免在这里建立第二份来源契约。

## 5. 次模优化的理论参照

原始论文：[Nemhauser, Wolsey & Fisher (1978)](https://doi.org/10.1007/BF01588971)，[公开原文](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf)，*Mathematical Programming* 14, 265–294。使用范围为摘要、§2 的次模性条件及 §4 的贪心界，不声称复现整篇优化理论。

对归一化、非负、单调次模函数和基数约束，经典逐条贪心具有 `1−(1−1/b)^b` 的最坏情形保证，因而至少达到 `1−1/e`。正文的支持函数违反边际收益递减，所以不能直接借用这项保证。本文提供的是一个适合 AMS 问题的有限反例与正控制，没有提出新的通用近似算法或新的复杂性定理。

## 6. 可引用的新增判断与不能写成结论的内容

可以引用：

- 在本研究明确规定的信息接口下，所有低阶效用观测可以相同，而高阶支持不同；有限计数与解析论证一致。
- 对指定的单条与双条前瞻算法，小而真实的局部收益会挤掉高价值三元支持；模块化正控制中单条贪心仍最优。
- 有替代支持路径时，标准证据集合的 recall 和并集 recall 都可能与完整支持发生不一致。
- 候选、预算和选择完整性的嵌套分解是描述性恒等式，单独不足以定位系统增益的因果来源。

尚不能引用为已证实结论：

- 真实 agent 记忆任务普遍具有三阶或更高阶互补；
- SG²RAG、AgentMemRec 或任何特定系统被该有限构造击败；
- 全集合方法在同成本下必然优于逐条方法；
- 名义召回率是 InMind 或其他 benchmark 准确率的严格上限；
- 增加多样性、减少重复或扩大候选池没有实际价值；
- 本轮结果证明模型因果使用了选中或引用的记忆。

后续模型研究应以 [protocol.md](protocol.md) 为起点，先实现并检查本地材料与契约，再决定是否执行 provider 调用。
