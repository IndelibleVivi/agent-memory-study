# 观察合同与允许的区分行动：有限研究协议 v1

Agent Memory Study editors · 2026-10-29

本协议在首次执行本目录 runner 前写定，材料与方法由同一实现者共同设计，不是盲法、预注册经验研究或 held-out 泛化实验。研究对象是有限、显式、确定性的有标签转移系统；经验样本数为 0。原始任务充分性研究保留在 [task-relative-sufficiency](../task-relative-sufficiency/README.md)，这里不改写它的结果。接续基准为原 PR #7 的 `759f7151cb40892d34b911191c9b8664a5e97c8d`，其历史 32-world 结果保持独立；本目录读取集成后的公开副本，不把新输入覆盖到原研究目录。

## 问题与竞争预测

研究判断：“相同观察”是否意味着“相同目标状态”？竞争预测 H0 是当前总分或答案已经分开需要辨别的机制；H1 是它们仍发生碰撞，而某个允许干预序列可以产生不同可见输出。第三种结果是当前合同下始终无法区分。三者由全观察类、目标标签及允许转移分别计算，不用目标答案作为测量输入。

三组原创家族分别测试：

1. **future-query**：四个 `(x,y)` 世界的当前摘要只显露 x，新增任务要求 y；side information 可显露 y。允许重访时，取得固定版本的源片段可以区分。任一 permission、availability、correct_revision、target_bound、adequate_coverage 关闭时，动作不可用；不把源仍存在当作源已到场。
2. **source-writeback**：当前答案同为“周五”，一个状态由有效来源支持，另一个从旧写回获得。撤回后还要读取，才出现“无支持”与旧值的不同观察；长度 1 搜索不能完成。另设禁干预、真正等价及变成本控制。
3. **score-scope**：两条轨迹总分同为 1，错误分别在 revision 与 scope，允许打开 trace 才可区分；加同预算不同成本的直接昂贵 probe 与两步廉价 trace 路径。零成本自环检查终止性。

三集合控制 `{a,b}, {b,c}, {a,c}` 两两有共同答案而全体没有。它专门反驳“只检查每对历史就足够”的命题，不冒充新增一般定理。

## 数学对象

Plant P 包含有限状态集合 S、初始可见 O(s)、声明侧信息 K(s)、动作集合 U、全定义确定性转移 δ(s,u) 及每步可见输出 λ(s,u)。动作是否获准由对全部状态相同的公开 gates 决定，故可用动作列表不会暗中编码目标。初始观察是 `(O(s),K(s))`。state handles 仅用于索引和审计，禁止当观察输出。版本、绑定与权限 gates 在此为合成访问政策，不是现实身份鉴定器。

Evaluator 在另一个 JSON 分支保存目标 θ(s) 和可接受答案 A(s,q)。观察类 C 的任务兼容性为 `intersection(A(s,q) for s in C)` 非空；全类交集检查独立于 pair search。最小冲突是按成员数最少的空交子集，多个并列时按稳定 handle 顺序选择。目标碰撞是同一观察类中 θ 不同的 pair，它不自动证明任何允许行动可区分。

对两个状态，从相同初始观察出发，寻找共同动作词 w，使两侧任一步输出不同。搜索只接收 P 及两个状态 handle，绝不接收 evaluator、gold 或 θ；它不会因答案合同不同就生成虚假的可见差异。若初始可见已经不同，空词成本为 0。动作是固定 open-loop 序列；不声称求解多假设 adaptive decision tree。

成本为非负有理数，统一每步 1 时最少成本就是最少步；变成本使用 product-state Dijkstra，优先成本、其次步数、再字典序。允许零成本环；负数、浮点、随机转移拒绝。无步数界时每个 ordered pair 只保留最小 `(cost,steps,word)`，非负成本意味着未来后缀不会因丢弃更昂贵到达而改善。设步数界时状态键扩为 `(left,right,steps)`，避免错误丢弃较贵但更短的前缀。每步、总预算和动作被拒绝均可审计。

不设界且 product graph 穷尽未发现区分，结论仅为 `indistinguishable-in-declared-model`。设任一界未发现时保守报告 `not-distinguished-within-bound`，即使有些个案也可能另行证明不可分。找到的路径报告 `minimum-within-declared-bounds` 或 `global-minimum`；有步数限制时不把局部最优冒充全局最优。

## 验证与结果解释

独立朴素方法枚举动作词，不调用优化搜索的 frontier/pruning，用最多 5 步的全部词核对小模型最小成本和每条轨迹。手工已知见证验证两步撤回/读取、两步廉价 trace、零成本环。分别改变输出、删除关键动作、移动任务、打乱状态/动作/评价顺序、重命名 handles；检查目标泄漏和无关字段不制造区别。

加入侧信息只细分初始观察类，故不能使原本全类兼容的任务失去兼容性。扩大任务族不能消除已有不兼容。增加允许动作不能提高无界最短区分成本；删动作不能制造原本没有的区分。该单调性不跨修改转移语义、状态集或成本定义使用。

runner 输出所有观察类、完整交集、最小空交见证、目标碰撞、所有 pair 的搜索结果、两侧逐步输出、成本、界和已展开 product states。results 绑定协议/源码/fixtures 的字节摘要，只用于复算身份，不证明来源真实性。源码或协议更改后重新生成并执行 --check。完整 portable packet 带输入与结果，可由 coordinator 的仪器重算，不携带代码执行指令。

## 限制

三家族为共同设计的有限构造，没有模型、自然材料、参与者、真实检索或现实因果识别。已知合成机制不代表 LLM 隐状态已知。找到最便宜动作词不保证现实实验最可行或科学价值最高；无界结论只覆盖显式有限 graph。不研究随机可区分性、错误概率、统计检验、自动化开放科学或跨多假设的最优策略。source gates 全开只允许在本构造返回片段，不证明现实访问一定成功。
