# 经验怎样进入选择：受控学习与纠正协议

署名：Agent Memory Study editors · 2026-09-21。
这是原创结构化标签预测实验。协议与实现曾在探索过程中修订，**不是盲预注册**。

## 问题与比较单位

给定当前任务、候选经验和已知内容，比较同一批反馈的四种使用方式：恒定输出
`irrelevant` 的无新增经验参照、Hamming 距离的首个最近案例、从训练反馈归纳的
深度至多 4 的二元 decision tree、实际梯度拟合的 4 类 one-vs-rest logistic scorer。
参照不是无记忆 LLM；小头是 44 个参数的分类器，不是 Jev / jevlike / BGE 的复现。

标签 `useful` / `redundant` / `irrelevant` / `harmful` 表示公开生成规则的分类。
它们没有经过真实任务、语言模型或人的效用判断。来源未核验也不在现实中自动等于
有害；这一人为约束只负责使本实验的修订范围可检查。

每个事件有 12 个候选。方法逐条预测，仅选入预测为 useful 的候选，因此可全部不用或
同时选中多条。报告逐候选分类、useful 遗漏、有害/无增量候选误选、逐事件集合完全一致、
全不选机会与成功数；不把多个预测行当成独立任务或计算显著性。

## 数据与输入表示

`fixture_build.py` 是公开生成器和标签规则；`fixtures.json` 是 runner 读取的冻结输入。
4 个 train、2 个 validation、4 个 test 任务名称组，分别有 24/12/24 个事件和
288/144/288 条候选。每组使用相同模板：普通/敏感范围 × 基础已知/额外已知/全部已知。
同事件的变化都留在同一组和 split。组名不同，**特征组合仍重合**；结果报告重合数，
不得称为新语义、分布外或新特征组合泛化。

10 个可观察特征：family/goal/parameter 是否匹配、前提是否齐备、工具是否可用、
候选 fact 是否已知、是否过期、是否有副作用、来源是否核验、当前任务是否敏感。
它们由显式字段比较产生，未使用 encoder；识别自然语言中的这些条件仍是未执行工作。
`expected`、row ID、候选位置、group 名称均不进入 inference vector。

标签优先级：范围/目标/参数不合 → irrelevant；过期/副作用/缺前提/缺工具 → harmful；
已经知道 → redundant；否则 v1 为 useful。v2 只把最后一类中“敏感任务且来源未核验”
改成 harmful。公开 oracle 仅生成/检查标签，不充当学习分支。

## 固定拟合与预算

Scorer 从零权重开始，400 full-batch steps，learning rate=0.5，L2=0.01（bias 不正则化）。
训练完全确定性，仅一次拟合，不制造 seed 重复；规则固定 depth=4，按 Gini 和特征顺序
确定分裂与 tie-break；案例固定 Hamming 距离和训练顺序 tie-break。保留 validation
分数但不用于挑参数、停止时机或模型；没有通过 test 搜索这些设置。

保存参数数、案例数、规则叶数、拟合步数和纠正样本数。总运行时间是一次本机测量，
包括所有分支与控制，不是推理延迟或方法间速度比较。四种实现的容量、归纳偏好和优化
方式不同，比较的是具体机制包，不能把差距唯一归因为存储形式。

## 纠正路径

完整 v2 train 来自相同观测，只按公开范围规则改标签。小量更新仅使用 train 中标签
确实改变的行，从 **v1 最终权重的副本** 开始做 40 steps，保留其余设置。四个处理均
使用相同的 scorer 结构，完整重训重置参数，其余保留或更新 v1 参数：

- frozen：记录改为 v2，参数不动；
- refit：用完整 v2 train 从零拟合；
- incremental：旧权重加仅纠正样本的 40 步更新，无 replay；
- guard：不训练，在原 scorer 预测 useful 且满足新范围条件时改成 harmful。

在未参与训练的 test 分别报告 changed（v1/v2 标签不同）、preserved（其余全部），
以及 boundary（preserved 中原本 useful 的已核验敏感候选或普通范围候选）。保存每行
v1/v2 标签、四种预测、分组计数和从 frozen 到处理后输出的转移矩阵。
Guard 只证明输出干预；参数变化与行为变化均不能证明来源影响被擦除。

## 控制与可反驳性

- 固定 seed=17 的训练标签置换，重新拟合三种学习器；测试标签不改。
- 一致重命名任务标识，检查输出不变。名称本来不入向量，此项仅证明实现不依赖名字，
  不证明对语义扰动鲁棒。
- Scorer 分别只用 candidate 的过期/副作用/核验字段、context 的敏感字段、六个
  context–candidate 关系特征重新拟合。报告信息删减结果，不称为独立因果贡献。
- 反事实测试核对同候选在已知内容变化后标签改变、同 context 换候选改变标签、
  敏感/普通与核验/未核验边界，以及真实全不选事件。
- `--check` 重新拟合、比较参数/规则/逐例预测/所有指标；只排除 Python 版本与单次计时。
  序列化浮点数四舍五入至 10 位，避免无意义的末位差异。它不下载 pretrained 模型。

## 探索与修订记录

首个未完成草稿曾查看生成器类别分布并改动候选；没有形成可接受的最终 receipt。
审查发现：遗漏可观察的重复字段导致特征碰撞、用 seed 改规则容量冒充重复、
“增量”从零训练、纠正阶段仍对旧标签评分、缺少全不选事件。这些路径已被本协议和
唯一实现替换。独立方法审查另指出生成标签自证、组间特征重合与机制包混淆；本协议
据此收窄主张并加入相应检查。以上修订先于本版本正式结果执行。

不根据后续分数调到某个方法获胜。若纠正失败、退化或简单方法相同，照实保留。
