# 历史怎样留下继续更新的能力

一段历史可以足够回答今天的问题，却不足以处理明天的新证据。保存下来的推荐、偏好标签或当前动作，有时压缩掉了系统以后改变判断所必需的信息。考察记忆是否充分，因而需要同时问：它现在能做什么，以及收到同一条新经验后，它还能怎样改变。

这是本轮最值得加入 AMS 的判断。它给“过去通过什么状态参与当下”增加一个要求：某些状态需要继承的是**继续更新判断的能力**。当前答案、预测分布与更新能力之间没有一个不依赖任务的统一大小关系。下面给出两组方向相反的例子：一个固定任务也可能需要持续增长的精确状态；完整预测分布又可能超过该任务真正需要保留的区别。

## 从已经得到的结论出发

AMS 在另一条研究分支的[《未来问题与记忆》固定版本](https://github.com/IndelibleVivi/agent-memory-study/blob/a618ecde843774442773577e318b776f9c63d417/study/entries/future-questions-and-memory.md)中，已经说明查询范围扩大可能细分历史类，确定性后处理不能重新拆开被压缩合并的历史，来源重访还需要权限、可用性、版本、绑定与覆盖条件。它也区分了单一正确答案与多个可接受答案：后一种情形需要整类答案集合有共同交集，两两相容不够。这些是既有积累。

本文接续一个较窄的问题：即使查询和损失函数保持不变，当前足够的状态是否也足够递归更新？已知规则、含噪观察与仍在学习规则的系统，会给出不同答案。这里采用的充分统计量、右同余、贝叶斯更新和信息界都是经典数学。本文的贡献是将它们连成可检查的论证，构造具体见证，并明确这些条件怎样限制 Agent Memory 的解释；不主张定理优先权。

## 十一月的 filtering 论文究竟支持什么

[Guo 与 Guo 的论文](https://arxiv.org/html/2611.02361v1)确实存在，核对版本为 arXiv:2611.02361v1，2026 年 11 月 2 日。阅读覆盖理论、关键诊断与证明附录。其 access-policy 过程有已知更新规则；递归状态优于长日志的部分结果，依赖具体读者和表示。作者报告的 query-time dependency retriever 在 256 个事件的比较中追平 filter；弱 parser 的部分 Bayes-filter 收益又被无记忆的 confusion remap 匹配。理论比特下界低于所测 token 预算，实际编码与读出成本仍明显存在。全文历史读者的失效长度属于实测结果。本文未运行其源码；在论文链接及标题、编号检索中没有定位到公开作者仓库。

这些诊断改变了机制归因：知道哪些字段需要更新、知道查询依赖哪些记录、校准解析错误、维护递归状态，可能分别产生收益。一个得到正确更新规则的系统，已获得竞争者可能仍须学习的知识。它可以是清晰的参照控制，但不能仅凭结果差距证明更会从经验中学习。下文进一步问：当观察含噪，或者规则本身尚未学定，有限状态的论证还能保留多少？

## 当前相同与以后仍然相同

先把语义完全固定。令 `O` 为事件字母表，`Q` 为查询集合，`a(h,q)` 为历史 `h` 下任务要求的确定答案。答案也可以是某个已声明概率模型的最优决策，不必是尚未发生的随机结果。假定所有有限事件串都有解释；若存在非法事件，需要把合法性和失败状态一起纳入合同。

只考虑当前回答，可以定义：

```text
h ~₀ h′  ⇔  对每个 q∈Q，a(h,q)=a(h′,q)
```

这允许一个一次性回答器合并历史。但是，递归更新器还要满足 `M(ho)=U(M(h),o)`。若已经合并的两段历史在同一个新事件 `o` 后要求不同答案，更新器收到完全相同的旧状态和事件，就无法恢复这一区别。

因此考虑所有共同后续事件串 `w`，包括空串：

```text
h ≡Q h′  ⇔  对每个 w∈O*、q∈Q，a(hw,q)=a(h′w,q)
```

这个关系是等价关系，并且具有右同余性质。证明很短：若 `h≡Qh′`，对任意 `o,w,q`，原条件已经覆盖后续串 `ow`，所以 `a(how,q)=a(h′ow,q)`，即 `ho≡Qh′o`。于是 `U([h],o)=[ho]` 不依赖代表历史的选择，递归更新定义良好；取空串又保证当前答案正确。

反过来，任何精确的确定性递归实现，如果把 `h` 与 `h′` 放入同一状态，收到同一串后续事件时便始终走过相同状态，输出相同答案。因此它不能合并被 `≡Q` 区分的历史。有限状态实现存在，当且仅当这个关系只有有限多个类；每一类本身就给出一个实现。这是经典 Myhill–Nerode 思路的任务化表述，十一月论文也明确使用了这种构造。

关键在量词：哪些事件解释固定、哪些后续允许、哪些任务和损失必须保持？只验证有限深度，得到的就是有限深度保证；只见过有限语料，也不能据此证明所有未来用户请求都等价。多个可接受答案的相交条件还需保留：相容关系可能不传递，不能直接当作上述确定答案等价类。递归实现必须另外满足后继状态的相容要求。

## 一个新证据怎样拆开相同的旧动作

设隐藏事实 `θ` 只能为 0 或 1。两段等概率历史分别给出 `P(θ=1)=1/10` 和 `1/5`。任务是在对错同价的损失下猜 `θ`，概率相等时选 0。当前最优动作都是 0。

后来收到信号 `+`，其观察通道为：

```text
P(+|θ=1)=4/5，P(+|θ=0)=1/10
似然比=8
p⁺ = 8p / (1−p+8p)
```

更新后的概率分别为 `8/17` 与 `2/3`。第一段历史仍应选 0，第二段已经应选 1。只保存“选 0”，没有保存判断距离改变还有多远。即使新信号完全正确地送达，压缩造成的更新困难仍然存在。

本研究枚举了历史、隐藏事实和信号正负的八个联合概率格。知道历史身份和信号的最优错误率为 `11/100`；只知道旧动作和信号，即使允许最佳解码，错误率仍为 `23/200`，差距恰为 `1/200`。这是指定概率构造中的精确风险差，不是任何现实 Agent 的测量值，也没有归因于语言模型的有限能力。

## 有限事件种类可以对应增长的学习状态

现在让系统学习一枚硬币的未知偏置：

```text
θ ~ Beta(1,1)
在 θ 给定后，各 Xᵢ 独立，Xᵢ ~ Bernoulli(θ)
观察 s 次成功、f 次失败后：θ|h ~ Beta(s+1,f+1)
T=s+f，下一次成功概率 p=(s+1)/(T+2)
```

推导只需把先验乘上似然：同一条二元历史的似然为 `θ^s(1−θ)^f`，均匀先验乘上它后，归一化得到 `Beta(s+1,f+1)` 密度。下一次成功的概率是后验下 `θ` 的均值，亦即两个 Beta 积分之比 `B(s+2,f+1)/B(s+1,f+1)=(s+1)/(T+2)`。条件独立和偏置不变使顺序能够在这里被计数替代。

事件字母表始终只有两个符号，未知参数只有一个。在固定时刻 `T`，成功计数从 0 到 `T`，得到 `T+1` 个不同的精确预测概率。因此即使把时刻 `T` 免费给读者，记忆也至少要有 `T+1` 种可区分取值，固定宽度至少为 `⌈log₂(T+1)⌉` 比特。两个整数是一种固定维度表示，整数的精度和存储长度却会增长。

这里完整潜在模型包含连续参数 `θ`。它没有推翻已知、无噪声、有限状态过程的充分统计量定理；它阻止把有限键名、有限事件格式或固定参数维度直接解释为有界的精确学习记忆。[Bialek 与 Tishby 的 predictive information 分析](https://arxiv.org/pdf/cond-mat/9902341)提供了经典先例：在其正则未知参数模型条件下，与未来相关的信息可随样本量对数增长。这里的计数论证独立成立，不能当作对该渐近理论的自然数据验证。

### 只保留一个固定决策任务，增长仍可能发生

刚才要求精确预测概率，似乎过强。现在只保留一个任务：按同样的对称损失猜下一次结果，平局选 0。令 `d=s−f`，最优动作是 `d>0` 时选 1，否则选 0。成功使 `d` 加一，失败使它减一。

考虑同一时刻 `T` 的两个不同计数，记 `d₁<d₂`。它们同奇偶，因此至少相差二：

- 若 `d₁≤0<d₂`，当前动作已经不同。
- 若 `0<d₁<d₂`，接上 `d₁` 次失败，第一者到零，第二者仍为正。
- 若 `d₁<d₂≤0`，接上 `1−d₂` 次成功，第二者到一，第一者至多为负一。

所以任何一对不同计数，都被不超过 `T+1` 个事件的共同后续串区分。模型给每个有限后续串正概率。虽然当前动作最多分成两类，递归决策等价关系在时刻 `T` 至少分成 `T+1` 类。任意固定有限状态字母表，都会在某个足够大的时刻合并不该合并的历史。

目标始终是匹配完整历史下的贝叶斯最优策略，并非保证猜中每次抛掷。该证明也没有声称，增长的精度在实际任务中一定值得支付。它说明“今天可以正确输出一个 bit”与“永远能正确更新这个决策”是不同保证。

### 已知的两状态模型也需要精度条件

连续未知参数并非唯一原因。设世界开始时等概率选中偏置 `1/4` 或 `3/4` 的硬币，此后保持不变；这两个隐藏状态、全部发射概率和先验都已知。观察含噪，但更新规则完全确定：

```text
高偏置／低偏置的后验赔率
  = [(3/4)/(1/4)]^s × [(1/4)/(3/4)]^f = 3^(s−f)
P(下一次为1|h) = 1/4 + (1/2) × 3^d/(1+3^d)
```

最优动作仍由 `d>0` 决定。相同 `d` 在任意共同后续后加上相同差值，因而始终要求相同动作。不同 `d₁<d₂` 则可以沿用上面的三种后续：若同为正，接 `d₁` 次失败；若同为非正，接 `1−d₂` 次成功；若跨过零，当前已经不同。故 `d` 正好标识这个决策合同的右同余类，类数无限；同一时刻仍至少有 `T+1` 类。runner 另外直接乘出两个模式的发射似然，核对各个计数对的分离结果，没有仅把 Beta 模型的动作复制过来。

还有一个容易混淆的量：令 `K` 为隐藏的硬币类型，则 `I(K;历史)≤H(K)=1 bit`，但精确后验和后续决策类仍可以无限多。“已经获得多少关于隐藏类型的信息”与“精确表示该信念、支持所有后续决策需要多少状态”衡量不同对象。固定时刻的状态数和熵仍然有限；这里没有声称工程必须使用无界精度。有限隐藏状态可以对应无限多个信念状态，一个实数形式的 belief 也不代表有限比特实现。含噪观察是关键前提，不能拿它否定一个已经直接观察到正确有限状态的无噪声模型。

## 反方向的约束：完整预测可能保存过多

比较 `Beta(1,1)` 与 `Beta(2,2)`。两者下一次成功概率都是二分之一，后续预测却不同：

| 条件 | Beta(1,1) | Beta(2,2) |
| --- | --- | --- |
| 接下来连续两次成功 | 1/3 | 3/10 |
| 已看到一次成功，再次成功 | 2/3 | 3/5 |

若决策阈值为 `0.63`，同一次成功之后就应做不同选择。为了避免时钟悄悄补回证据量，构造把两段历史都定义成一个批次事件：共同先验之后，一段收到空批次，另一段收到一次成功加一次失败；只保存均值，丢弃批内计数。若额外提供样本总量，它就是需要计入的侧信息。

然而，对阈值固定为二分之一的对称任务，这两个后验在**所有共同伯努利后续串下**都要求相同动作。它们最初的 `s−f` 同为零，任何共同后续又给它们增加同一个差值。完整未来预测能够区分它们，固定任务的递归动作却无需区分。

因而不能把 predictive sufficiency 自动提升为每个决策任务的最小记忆标准；也不能因为现在的决定相同就丢弃所有不确定性。需要保留什么，由任务损失和允许的更新共同决定。更宽的任务族、不同的提问成本或改动后的决策阈值，都可能重新需要此前无用的精度。

## Agent 的未来还包含自己会采取的行动

[原始 causal-state 理论](https://csc.ucdavis.edu/~cmg/papers/cmppss.pdf)按整个未来的条件分布区分过去；其平稳随机过程前提需要保留。Agent 与环境交互时，还要指定谁选择未来动作。[原始 PSR 论文](https://papers.neurips.cc/paper_files/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf)的 tests 本身就是动作与观察序列；[ε-transducer 论文](https://arxiv.org/pdf/1412.2690v3)则把未来输入纳入通道描述。

可以把受控预测状态示意为：

```text
z(h) = 所有 k 和动作序列 a₁:k 下，
       环境在执行这些动作时给出 o₁:k、r₁:k 的条件分布
```

这里假定固定的环境核，动作是指定的干预。这个定义没有授权从任意观察日志直接识别干预分布。两种隐藏模式在动作 `wait` 下总是输出同一结果，在 `probe` 下却分别以 `0.2` 和 `0.8` 的概率输出 1。只含 `wait` 的日志无法验证 `probe` 下是否相同。当前行为策略下的预测等价，可能在行动范围扩大后失效。

有限 POMDP 具有不超过其最小隐藏状态数的线性 PSR 维度，是带前提的存在性结果。发现适当 tests、估计更新、到达有辨别力的状态、确定需要多少数值精度，都是进一步的问题。一个来自被动序列的“causal state”，也不直接证明向 LLM 展示某段记忆产生了行动收益；后者需要自己的干预与评价合同。

开放个人记忆还会遇到目标、权威来源和事件含义改变。把时间附在状态中，可以索引变化，却不会自动得到正确而紧凑的变化模型。长期积累旧偏好的证据，也可能让平稳模型过度抵抗真实的新偏好。上述下界不构成永久保留全部过去的建议。

## 重新解释历史，需要补回多少信息

旧 AMS 已经说明丢失的区别有时能通过来源重访恢复。现在给这件事一个数量边界。令 `M` 为旧记忆，`Z` 为新合同真正要求的有限目标状态，`E` 为补充读取所得消息。精确恢复要求：

```text
H(Z|M,E)=0
I(Z;E|M)=H(Z|M)−H(Z|M,E)=H(Z|M)
H(Z|M) ≤ H(E|M)
```

若消息最多有 `2^B` 种取值，就必须满足 `B≥H(Z|M)`。零错误、固定宽度的更直接下界是：

```text
B ≥ ⌈log₂ maxₘ |supp(Z|M=m)|⌉
```

理由是：给定任意一个旧状态，每个仍然可能的不同目标都需要不同的消息编码。熵界依赖分布；最大类的计数界要求最坏情况正确。熵不直接等于单次可变长编码长度，更不等于 token、延迟或 API 费用。

具体地，历史有四个独立公平 bit `(X,Y₁,Y₂,Y₃)`，只留下 `M=X`。补回完整后三位需要三比特；若新任务只问它们的奇偶性，一比特就够。重新下载全文可能强于恢复目标所需的区别。

再假设每次读取每个缺失 bit 都以 `0.1` 的概率独立翻转。一次读取后三位仍有约 `1.406986780768` 比特条件熵，来源可读并未使恢复确定。精确枚举给出每位的最佳错误率：读取一次为 `0.1`，三次为 `0.028`，五次为 `0.00856`。这些改善严格依赖独立通道；重复同一个解析错误、读取错误版本或拿错对象，都不符合该模型。

因此，来源的可用性之外，还要问这次观察究竟提供了多少目标相关信息，剩余多少不确定性。这个要求深化了既有重访条件，没有替代它们。

## 已执行的证据与它没有证明的事

输入、标准库 runner、方法和结果保存在 [recursive-sufficiency-study](../../research/recursive-sufficiency-study/README.md)。[结果文件](../../research/recursive-sufficiency-study/results.json)来自实际执行，绑定源码、输入与协议的 SHA-256。全部概率运算使用精确有理数；熵只保留十二位小数。没有模型调用或经验样本。

| 检查对象 | 实际执行内容 | 支持范围 |
| --- | --- | --- |
| 当前动作碰撞 | 枚举八个联合概率格，重算两种最优风险 | 指定分布中的不可恢复风险差 |
| 固定任务的递归区分 | 在 T=1、2、4、8、16、32 检查所有计数对；保存 T=8 的 36 个后续见证 | 一般证明的有限实例核对 |
| 预测与动作的不同要求 | 重算两个 Beta 后验及已知两状态模型 | 具体精度、损失与观察条件 |
| 来源恢复 | 枚举有限历史与独立翻转通道 | 声明目标和通道下的信息与错误率 |

这些构造没有检验自然语言 Agent 是否会学到规则，也没有估计长期个人记忆的平均收益。精确保证可以被非常罕见的后续串限制，不能直接替代平均后悔值或风险预算。检查数量不提供统计显著性；无界结论来自上面的任意 `T` 证明。

近似和有限时间范围会改变问题。如果只要求到某个固定时刻，可能的计数有限；若只要求小的额外决策风险，就不必保存每一个不同后验。例如真实概率 `p` 与近似概率 `p̂` 相差至多 `δ`，二者若在二分之一两侧选择了不同动作，对称损失下多出的风险为 `|2p−1|≤2δ`。但这是给定当前概率误差的保证，尚未证明有限精度递归更新能够在无限时间里维持它。[预测率失真研究](https://arxiv.org/pdf/0708.1580v2)提供了把保留成本与预测损失共同写入目标的经典框架；失真对象与未来分布仍须明确指定。

尤其需要分清三种预算：容纳多少精确状态的最坏情况比特数，某个分布下的平均信息量，以及实际读写的计算预算。一个长后续串即使概率很小，仍能否定“所有后续都正确”的有限状态保证；在允许小概率错误的合同里，它可以只占很小风险。反过来，一个平均信息很小的信号，也可能具有很长的单次编码或很高的读取成本。这些量之间需要额外的编码、分布与计算假设，不能只因为都出现“容量”一词就直接换算。

## AMS 接下来值得坚持的区分

“继承关系”可以继续作为研究入口，不过研究对象应包含更新规则及其不确定性。一个可复用案例、一条稳定技能和一个后验状态，保留的反应能力各不相同。评价它们时，只看当下输出是否改善，会漏掉未来相同证据下是否还能适当地改变。

已有[《经验怎样成为选择策略》](experience-becomes-policy.md)把经验、特征和策略改善分开，是这里可直接接续的位置。下一步有区分力的研究，可以让两个系统先产生相同的当前决定，再给它们相同但强度不同的新证据；对照已知规则、学习规则、固定任务与阈值变化，并把外部时钟、来源重访和参数精度计入可见状态。验收应比较决策风险与更新轨迹，同时保留反方向控制：存在预测不同而指定任务始终等价的历史对。这仍是候选协议，本文没有执行自然语言版本。

本轮最强的判断是：**压缩应保留哪些未来更新能力，需要成为明确研究问题；“当前任务足够”无法代替它。** 同时，未知规则不意味着每个任务都需要无穷记忆，完整预测也不是所有决策的最低要求。AMS 后续需要决定的是优先研究哪一种保证：开放任务下可重新解释的证据保存，还是给定任务与风险预算下足够精确的可更新状态。两者都能深化现有纲领，但它们会选择不同的保留成本、反例和验收标准。
