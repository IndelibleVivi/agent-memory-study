# 经验留下什么：事前价值、学习与保持沉默

2026-11-13 · Cove · AI-assisted research

**本轮最值得坚持的判断是：对于承诺持续接收新证据的记忆系统，压缩目标应包含未来更新所需的区别；只保证当前答案充分还不够。** 当前答对、在同类任务中再次答对、获得一种可更新的能力，是三种不同强度的要求。一个系统可以在前两项上成功，却把第三项需要的区别丢掉。一次性回答或只读档案可以采用较窄目标，不能把这个要求不加条件地施于所有记录。

这个判断来自三个相遇的对象：公开模型输出的复算、AMS 原学习器的新组合干预，以及历史等价的独立推导。它没有把不同证据混成一项大型实证研究。本文负责贯通这些机制；完整证明见[今天给出同一答案，明天还能一起更新吗？](history-and-update-sufficiency.md)，新实验输入与结果分别由原研究目录和[公开效用复算包](../../research/task-conditioned-utility-study/README.md)维护。

## 1. AMS 已经知道了什么，这轮还缺什么

AMS 已经积累了几类可以重新执行或定位的知识。FTS5 实验使候选仍在与实际入选分开；更正研究使新旧时间与适用范围分开；缓存撤回研究使删除来源位置与重算派生影响分开。它们没有共同证明一种统一的记忆定律，但各自排除了一个容易混淆的解释。

最近的工作也远不止结构化演示。[侧信息研究](memory-value-side-information.md)已经证明在固定任务中，读者已有信息可以反转两条记忆的用途次序，并执行了短文本 reader 对照；[组合证据研究](memory-evidence-complementarity.md)已经给出单条、双条价值为零而三条共同充分的见证。因此，本轮不把“用途具有条件性”“信息会互补”重新署为新发现。

[范围与修订研究](scope-memory-after-revision.md)还有真实的 question-blind writer 与两种 reader。原选择题无记忆仍能得到 65/72 和 68/72；去掉选项线索后，沿用同一批记忆的 22 道有证据任务中，无记忆均为 0/22，完整历史均为 22/22。普通摘要与条件记录的次序随 reader 改变，弃答与错误值的权衡也不同。这已经迫使 AMS 修订评价对象，不能再泛称它尚未进入自然语言。

仍未解释清楚的是：在写入时不知道未来问题，怎样把这些局部结果转成保留决策？一种表示如果足以回答今天的问题，它能否支持明天接收新证据？一个学习器在旧测试集上满分，究竟识别了什么规则？本轮主要推进这三个缺口。

## 2. 事后帮助与事前值得保留，需要不同的反事实

### 2.1 测到的首先是一次曝光的作用

固定任务 q、读者及其已有上下文 C、其他记忆 B、插入位置和工具预算。令 Y1 是提供候选 m 后的结果，Y0 是不提供它的结果。最直接的效用是：

```text
Δ(m, q | C, B, reader, exposure) = E[Y1 − Y0].
```

这里的条件不是装饰。一条已经由当前工具输出确认的事实，可以没有增量；同一段建议插到错误版本的任务里，可以有负值；压缩改变了遗漏内容和阅读成本，也改变了干预本身。随机模型需要明确重复与随机化单位。一次正差值并不会自动识别可靠的总体效应。

[What Is This Memory Useful For? v1](https://arxiv.org/html/2611.03930v1)为这种测量提供了公开记录。其 answer-bearing screen 消费 gold，用于选择可研究的配对；writer 的设计则不看未来问题。两者的信息边界不同。作者自己明确 screen 不能部署为检索器，且 answer-bearing 不等于实测有益。它支持条件曝光研究，无法单独解决事前 admission。

本轮固定官方仓库 `386ac65a8b5fc46414abdd2755375f2a52d4d3b8`，执行官方 headline 和 fixed-context 分析，再独立重算归档输出。主切片的 2,599 条重复记录对应 1,157 个 memory–task cells、60 条 memories 和 35 个 source episodes。官方 **memory-weighted bearing-minus-control** 复算为 `+0.3348611111`，memory bootstrap 区间约 `[+0.209,+0.463]`，episode bootstrap 约 `[+0.196,+0.475]`。这是两个 stratum 的效用差，不能改写成“随便加入记忆，正确率提高 33.5 点”。

| 已保存配对 | Cells | 错→对 | 对→错 | 原本错误 | 原本正确 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Answer-bearing | 139 | 50 | 2 | 123 | 16 |
| Matched control | 146 | 10 | 6 | 125 | 21 |
| Random task | 872 | 82 | 26 | 693 | 179 |

同一 cell 的重复输出没有产生新的任务。表中是复算结果，机会条件化思想和作者附录的相关诊断归原作者。输入散列、去重、加权、聚类单位及独立分析见[研究包](../../research/task-conditioned-utility-study/README.md)。本轮没有为这张表新调用模型。

### 2.2 保留价值要对未来政策积分

在一个刻意简化的单步模型里，未来任务分布为 D，调用规则为 g(q)，写入不会挤出其他记忆，收益可加，则：

```text
V(D,g,m) = E[q~D][g(q) Δ(m,q)]
           − c_write − c_store − E[q~D][g(q)c_read(q)].
```

这说明“效用依赖任务”完全允许一个期望价值标量；这个标量属于指定分布、读者与调用政策。改变这些条件，就需要重新估计。若经验影响未来任务选择，或者写入改变其他条目的检索机会，应比较两条完整的动态政策：从相同写入前状态出发，分别保留和不保留，在相同外生随机环境下展开未来回报。后续轨迹允许分叉，不能事后强制匹配成同一历史来消掉干预的中介。

未来任务不可预知时，没有不带假设的唯一保留最优解。一个小反例已经足够：历史里有两个独立公平 bit，只能保留一个 bit。未来若只问第一位，保留第一位最优；若只问第二位，结论相反。要对两种问题都零错，编码必须能恢复四种原历史，一个 bit 的两个状态不够。这里缺少的首先是未来需求的约束，单独提高摘要模型能力不能解除容量矛盾。

可以采用历史需求分布、任务族、最坏情形、分布不确定集合，或给某些记录规定不得丢失的约束。这些都是明确的研究选择。不能把未知未来偷偷替换成评价集，也不能把所有未测到效用的记录判为无价值。

### 2.3 信息的选择价值与强制注入的影响

已有侧信息文章讨论的理想 value of information 有一个关键前提：决策者可以免费忽略新增信息。因此可用决策集合扩张，最优值不会下降。真实 reader 被强制读入一段文本时，注意力、推理轨迹、延迟和候选竞争都可能变化；实际政策没有自动实现那个最优忽略动作。

因此，应分别研究“留下以后可选择使用”与“每次自动写进当前上下文”。保存可核对的来源、维持紧凑工作状态、在合适时候回源，是一种候选分工；它是否合算取决于访问成本、证据可获得性与任务分布。它不是不计成本的保留全部建议。

压缩实验也有两个不同的成本问题。此次 fixed-context 复算在披露的 cache 暴露排除后保留 77 个 bearing cells：Raw 的平均曝光效用 `+0.35065`，Summary `+0.03896`，Structured `+0.01299`。Summary−Raw 约 `−0.31169`。这个配对使用 filler 固定总长度，说明这套 writer 在这些任务上的差异不能仅由总长度解释。现实系统可以把空位交给另一条相关证据；filler 没有评价这个替代用途。因此它与 AMS 既有预算挤出研究可以同时成立，也没有证明所有压缩都劣于原文。

## 3. 记忆什么时候应该保持沉默

### 3.1 先数清帮助与破坏的机会

对二元正确性，定义：

```text
p = P(Y0 = 1)
h = P(Y1 = 1 | Y0 = 0)     # 可救回时的救回率
e = P(Y1 = 0 | Y0 = 1)     # 已答对时的破坏率
E[Y1 − Y0] = (1−p)h − pe.
```

最后一行由四种结果转移直接展开。若把一次调用的成本换成同一收益单位 c，在固定 h、e 的标准化情景里，正净收益要求：

对随机 reader，h、e 的转移解释还依赖预先规定的重复与配对方案；平均效用由两臂均值确定，一次采样翻转却不自动成为稳定的记忆用途标签。下面的计算以已声明配对为前提。

```text
(1−p)h − pe > c;
若 h+e > 0，则 p < (h−c)/(h+e).
```

公开 bearing 数据的总体破坏率是 `2/139`，但已有正确结果被破坏的条件率是 `2/16`。前者看起来很小，部分原因是这批题原本就极难。两次事件不支持精确的总体风险估计；不同聚类 bootstrap 给出的区间很宽，详见复算包。

用同一批数据的 h、e 点估计做**假想**标准化，零成本临界 p 约为 0.7648。这个数不是模型升级预言：升级会同时改变 h、e，子群也会变化。它只排除一种推断——旧读者上正的平均增益，不能独自保证新读者也应按同样频率调用记忆。若 e=0 且成本为零，提高 p 只压缩帮助空间，不必产生负收益。

### 3.2 沉默应是可比较的行动

一个实际控制器至少应有四种可比较路径：直接使用当前信息；调用历史记录；查询有明确当前效力的来源；在缺关键条件时请求澄清。历史正确性并不提供当前权威性。遇到旧版接口建议，当前版本文档可能比更多相似旧案例更有价值；若当前输入已经包含正确版本，再检索可能只增加冲突。

这些判断需要以部署时可见的特征实现。上面的 p、h、e 是研究者从配对结果估计的量，不能让运行时 gate 读取正确答案，也不能把模型自报 confidence 当成已校准的 p。门控本身要付成本；评价还要报告遗漏帮助、错误注入、净收益和延迟，不能用“很少出错”掩盖从不提供帮助。

下一项自然语言实验宜固定 writer、候选池与 reader，对同一任务比较不注入、真实记忆、同位置等长无关内容、可替代的当前证据；训练门控与测试门控按独立情境划分。再分别改变 reader 和任务分布，比较全调用、全沉默、成功频次监督与配对增量监督。这是尚未执行的协议，具体要求见[工程交接](../../docs/research-renewal-2026-11.md)。

### 3.3 写入的克制与读取的克制回答不同问题

[When to Remember, When to Abstain v1](https://arxiv.org/pdf/2610.07100v1)研究冷启动抽取的 source support，并按类别设置信心阈值。在 100 个合成人设的 4,715 条候选上，values 类更难得到 judge 的支持；按人设划分的重复交叉验证中，定向阈值在相近保留比例下改善支持率。这里没有真实用户效果验证。覆盖度来自 judge 临时枚举事实与 lexical attribution；不同 judge 对 values 的支持水平差异明显。

它打开的有用问题是：未来任务还未出现，仍可以检查当前写下的断言是否超出来源。事实支持与未来用途是两个目标。一个忠实记录可以暂时无用；一个无根据的猜测也可能碰巧帮助某道题。把后者的成功直接训练成用户记忆，会把一次幸运变成长期状态。

还能进一步推导阈值为什么应当有条件。在只优化来源支持的二元筛选里，若 r 是正确校准的 source-support 概率，保留无支持断言的代价为 λ，拒绝有支持断言的代价为 μ，且 λ、μ 非负、和大于零，则保留优于拒绝当且仅当：

```text
λ(1−r) ≤ μr  ⇔  r ≥ λ/(λ+μ).
```

成本一致时，校准概率空间可以使用同一阈值。这是来源支持的局部损失模型，完整保留政策还需要未来价值和其他成本。类别阈值可能是在纠正不同抽取器的分数尺度；也可能反映不同成本。该论文每类使用独立 extractor，不能据此将差异全归于语义类别的本性。“一个全局原始 confidence 阈值表现不好”也不等于全局概率阈值在数学上不成立。这是本轮的决策论解释，没有重新运行其内部生产管线。

## 4. 经验怎样成为能力：要识别学到了什么

### 4.1 六种学习对象

| 经验留下的东西 | 被改变的对象与反馈 | 能力主张还需要什么 |
| --- | --- | --- |
| 案例 | 可检索内容与相似性关系；任务成功或人工修订 | 新情境的适用性；与相同上下文、无历史和替代案例比较 |
| 程序性技能 | 可执行步骤、调用接口、前后条件；执行成功或测试 | 新实例可执行；保持工具和人工预置流程的公平基线 |
| 归纳规则 | 条件、结论与优先级；标注或任务反馈 | 不变关系与冲突组合；训练没有识别的优先级须显式暴露 |
| 模型参数 | 预测或决策函数；梯度与损失 | 支持外迁移、能力保留；分开特征工程与拟合所得 |
| 记忆操作政策 | 何时写、改、删、查；延迟任务回报 | 对记忆轨迹的贡献归因；与只改变 QA 能力的对照 |
| 提供者路由 | 选择哪种存储／检索机制及其内容；强制探索、judge、后续成功 | 内容与路由分开；持有任务与新任务分开；计算预算一致 |

这个表不排列机制优劣。同一个系统可能同时学习多行，反馈也未必需要每次操作的精确因果标签。问题在于：当我们说“学会了”，证据究竟支持哪一行。

### 4.2 两种新训练路线的信用分配

[MemAgent 的异构提供者论文](https://arxiv.org/html/2609.32521v1)学习 Begin/In/End 路由。它的 End 奖励组合后续命中频次与成功率，没有减去无记忆反事实。一个独立反例是：A 被五道本来就能答的题命中，全部成功；B 只被一道本来会失败的题命中，并救回它。在论文 H=5 的公式下，A 得 1，B 得 0.6。这个 reward 可以训练出好策略，却无法仅凭自己识别因果存储贡献。论文还明确披露 53 道 GAIA L1 同时参与填库和评价；112 道 L2/L3 及另外两套 benchmark 才是留出测试，整体提升不能统称为严格未见迁移。

[UMA](https://aclanthology.org/2026.emnlp-main.1299.pdf)则从同一任务盲记忆轨迹分叉到多道 QA，用平均回报监督维护 session。它更直接连接写入与未来用途，仍不能把 session 回报视为每次 CRUD 的独立贡献。其 16k TTL/AR 平均分从完整系统 75.86 降到去 raw-context retrieval 的 57.74，说明原文通道在被测系统中具有重要作用，不能将全系统能力都归于结构化 bank。这里的 MemAgent baseline 是另一篇同名长上下文压缩工作，不能与上述提供者路由混同。

### 4.3 AMS 已执行的新反例：正确特征仍能学出错误关联

[原学习实验](experience-becomes-policy.md)的案例近邻和小分类器在旧测试集均为 288/288。原文已经披露训练支持重合。本轮继续问：在特征语义全部正确时，学习器是否掌握了原规则要求的不变关系？

保持原训练与预算，枚举全部 `2^10=1024` 个合法特征向量。原训练只有 36 个不同向量；988 个未见组合全部是负向选择，v1 的 4 个 useful 向量都已见过。于是“域外总分高”仍不说明会在新情境中找到有用经验：恒定拒绝已经得到 1020/1024 的选择正确。

更具体地，一条已过期记忆仅将 verified 从 false 翻为 true，其他条件不变。原 gold 标签也不变，但三种学习器都会在某些组合中把它改判为 useful。训练模板只让有效候选拥有 verified=true，这项本不影响 v1 答案的属性获得了捷径作用。

| 512 对 verified 翻转 | 类别预测改变 | 是否选入改变 |
| --- | ---: | ---: |
| 最近案例 | 508 | 254 |
| 深度四决策树 | 512 | 256 |
| 小分类器 | 75 | 38 |

再去掉 v1 不使用的 verified/sensitive，按原预算重拟合，小分类器的选择正确达到 1024/1024，但四类标签仅 360/1024。最近案例仅反转训练案例顺序，就从类别 1024/1024 变为 184/1024；是否选入仍然全部正确。原因是训练从未让范围不符与危险条件同时出现，scope-first 与 hazard-first 两条规则在旧数据上完全一致，却在新域的 840 个组合上赋予不同类别。平局顺序补入了训练未识别的优先级。

这项结果改变了原文下一步的顺序：先在给定特征下解耦共现与机制，再处理从自然语言识别条件。它没有推翻旧更正实验，也没有证明结构化学习无用。删除字段的对照使用了设计者知识，只适用于 v1；v2 需要这些字段。完整逐例结果、事后追加控制与四项行为测试见[支持审计](../../research/decision-learning-study/support-audit.md)。独立自然经验样本数仍为零。

### 4.4 不应只保留训练奖励已经承认的东西

[Latent learning v3](https://arxiv.org/html/2509.16189v3)研究训练时经过、却未成为当时目标的信息怎样被新目标使用。它在受控任务中发现 episodic retrieval 有助于这种迁移，但采用 oracle retrieval，且消除训练中的 ICL 支持结构会削弱收益。

这个结果与只保留当前高 utility 的策略构成有意义的张力。想象导航时路过一家修理店，当时任务是找车站；后来车坏了，旁路观察才获得用途。保留可重新解释的经历具有选择价值。但“有朝一日可能有用”不提供无限保存的正当化：真实 admission、检索、成本与遗忘仍待解决。更窄也更稳的结论是，当前任务监督没有覆盖的经验，仍可能为后来能力提供材料；处理这些材料的能力也需要学习。

## 5. 两段历史今天一样，明天还能一样吗

已有的有限任务充分性研究已经说明，给定未来问题族，压缩只要保留正确答案所需区别即可。本轮把“未来”推进到**共同经历一段新事件之后**。若两段历史被合成一个状态，却在相同新证据下应当走向不同决定，递归更新器便无法同时正确。

一个数字例子：两段历史分别得到某事件的后验概率 0.1 与 0.2，当前以 0.5 为行动阈值，两者都选“不采取行动”。新的证据似然比为 8。更新后分别为 `8/17≈0.4706` 和 `2/3`，决定分开。只保存上一轮的行动，无法知道这次该走哪一边。完整精确概率见证给出 Bayes risk `11/100` 与合并状态后的 `23/200`，差 `1/200`；这是枚举证明，不是模型基准。

反过来，保存完整预测分布有时又超出任务需要。Beta(1,1) 与 Beta(2,2) 的证据强度不同，未来成功一次后预测也不同；但在固定对称 0–1 预测、阈值 0.5 的任务里，所有共同续串都保留同一行动，因为决定只依赖成功数减失败数。任务改变为不同错误代价，合并关系就可能失效。

[配套理论文章](history-and-update-sufficiency.md)给出右同余、可递归状态的构造、部分可观测环境与 PSR／causal states 的边界，也证明一个容易被忽视的事实：有限事件字母表、甚至有限隐藏状态，都不保证精确决策所需记忆只有固定有限个状态。持续积累的证据可能要求越来越多可区分的 belief。有限维参数不等于有限 bit；允许误差、有限时域或限制可出现的续串，才可能改变这个结论。

[Rate-Limited Filtering v1](https://arxiv.org/html/2611.02361v1)最值得借鉴之处也在其自我拆解：知道规则的显式状态对被测长历史有优势，但依赖感知的查询时检索能匹配写入过滤；所谓校准 Bayes 增益在十个 parser×checkpoint cells 上可由 memoryless remapping 匹配。论文因此将收益归于混淆校正。它的 bit 下界低于全部实测 token 预算，不能拿该下界解释已观察到的模型瓶颈。已知规则、正确解析、可解码表示与 reader 能力仍是分别需要成立的条件。

## 6. 构建顺序改变了什么，不能只看一次回答

[RoutePrism v1](https://arxiv.org/pdf/2609.34160v1)保持记录内容、标识与时间戳，改变它们进入构建器的顺序，再追踪 source、编译后的上下文和回答。排列是否保持答案的两次模型筛选不看 gold 或路由输出。其后支持记录 audit 看 gold，不看生成答案；四种干预为 support present、support absent、restored support、同池 non-support replacement，保持来源数、序列化与总 token 长度。PersonaMem 的主要恢复估计只对应恰有一条支持记录被替换、且能完成四条件匹配的 33 个 queries／21 个 users。不能把这项局部支持恢复读成所有任务的收益，也不能从较早支持容易被 last-arrival 规则丢弃，推导普遍倒序更好。

附录 A.5 还有一个值得独立理解的恒等式。设两条固定构建路径下，reader 的回答分布分别为 p、q，各次调用独立抽样。跨路径回答不同的概率 C，与两条路径各自内部随机分歧的平均 W 为：

```text
C = 1 − Σ_a p(a)q(a)
W = 1 − [Σ_a p(a)^2 + Σ_a q(a)^2]/2
C − W = (1/2) Σ_a [p(a)−q(a)]^2.
```

最后一行把平方展开即可得到。若两条路径都在 A/B 之间各以一半概率回答，单次跨路径分歧率达到 50%，但 C−W=0：没有行为分布改变的证据。若一条恒答 A，另一条恒答 B，残差为 1；若 A、B 都是错的，准确率差仍为零。这个公式属于论文，本轮把它接到 AMS 对“变化作用于什么”的问题：来源集合改变、实际消息改变、行为分布改变和任务效用改变不能互相代替。有限样本估计可为负，也不能拿残差当作准确率提升。

这还为继承关系提出一个限制：即使 source IDs 一样，编译出的正文也可能变化；保存 ID 不能单独证明作用相同。反之，两个不同来源集合也可能提供相同的决策内容。一个真正有区分力的 trace 应当绑定实际送达材料，而非只保存血缘标签。这与 AMS 既有 representation runner 的绑定要求相接，并未由此证明它已识别现实构建顺序效应。

## 7. 行动评价与持续学习仍要分开

[MemoryArena v2](https://arxiv.org/html/2602.16313v2)让较早子任务的产物进入较晚子任务，向真实工具行动靠近。其成功率有领域区别：购物和旅行要求全部约束，搜索与形式推理的 SR 以最终子任务为准，PS 则统计中间进度。把这些指标压成一个“记忆能力”数，会消去任务合同。

我们阅读了论文方法与附录，并检查官方源码 `6cd9de14b71915e39ac742a20dc33785e14b6aab` 的 session、memory entry 与 judge-feedback 路径，未运行 benchmark。此类相互依赖的任务可以测延续一个计划，却不自动证明形成了可迁移技能。若要谈持续学习，还需独立的能力探针、获得前后对照、延迟和干扰后的保持，以及新任务迁移；预填流程、更多上下文和模型原有能力都应有相应控制。

[Memory-Centric Continual Learning v1](https://arxiv.org/html/2610.29357v1)将这些评价维度带到记忆政策，并提出资源约束的 attainable frontier。它的 scaling law 是带条件的假说，部分图是合成示意。一个被忽略的逻辑区别是：允许忽略多余资源时，最优政策族扩张，其最优值不会更差；某个现成系统随着经验增加而下降，并不与这个最优边界矛盾。反过来，最优边界的单调性也不能保证某种实际 memory 算法。其 IdeaBench 非单调观察的 8,192 与 32,768 token cap 都未实际绑定，占用约 3,858 tokens，不能解释成“库满了所以退化”。

因此，AMS 继续追踪继承关系，但给它增加一个更严格的问题：**在什么未来观察、任务与损失下，这种继承保住了可改变决定的能力？** 仅列出来源、载体和更新函数，还不能选择该保留哪些区别。

## 8. 本轮改变了哪几项研究决定

第一，保留政策不再直接继承局部 utility 标签。论文的 gold screen、真实曝光对照、部署门控和长期保留分别记录；成本和未来分布属于定义的一部分。固定上下文长度与压缩空间的替代用途分别评价。

第二，学习研究先检查支持与不变关系。旧分类分数仍作为历史事实保留；新增向量干预改变了对它的解释，原文与 inquiry 的下一问已相应修订。

第三，表示研究增加可更新性。即时答案充分、预测充分和对共同续串的决策充分各自有用途。开放个人记忆中，用户、事件语义和目标都可改变，不能从已知有限规则任务直接继承全局充分性保证。适用范围变化时，需要重新检验合并的历史，或有条件地返回来源。

第四，沉默成为有代价、可学习、可检验的动作。它与删除、遗忘、回答弃答、写入拒绝分别处理。一个系统可以保留忠实历史，同时在当前任务里完全不调用它。

本轮没有训练新的 LLM，没有证明任何普适的保留算法，也没有把公开结果复算升格为论文全部复现。完整来源版本、实际阅读范围、研究与工程验收见[研究接续交接](../../docs/research-renewal-2026-11.md)。最有价值的后续研究将检验：**当前无收益、但会改变后续学习的区别，怎样在有限成本下被识别和保留。**
