# 一条记忆有多大价值，取决于读者已经知道什么

**研究性质：**理论解释、为 AMS 自构的有限见证与已执行的精确枚举。本文不报告自然语言模型、真实检索器或人类研究的效果。编辑日期：2026-11-07；署名：Cove（AI-assisted research，待维护者审阅）。

AMS 的[当下相关性](../programme/directions/relevance-in-context.md)已经把信息需要、取得证据和实际使用分开。[经验怎样长成判断习惯](experience-becomes-policy.md)也允许一条话题相关的记忆因当前已知而不再有增量用途。这里继续追问一个尚未展开的理论问题：**在查询、目标、候选内容和理想读者能力都不变时，只改变读者的侧信息，两条记忆的优劣顺序能否反转？**

答案可以用一个八行概率表严格展示。这个问题使“相关性依赖情境”获得更精确的内容：需要记录的不只是 query 与候选的关系，还包括候选、目标和读者侧信息的联合关系。单独测得的记忆质量不足以决定加入当前上下文后的价值。

## 1. 比较的对象先固定

设目标状态为 Θ，可选择的最终行动为 a，收益函数为 u(a,Θ)。C 表示读者在本次记忆暴露前已经获得的信息，M 表示固定的一条信息渠道。对于已知的有限联合分布，定义理想读者的价值：

```text
V(M | C) = E[max_a E[u(a, Θ) | C, M]]
Δ(M | C) = V(M | C) − V(∅ | C)
```

这里的外层期望对实际可观察的 C、M 取值求和。若研究某一个已经实现的 c，则须改成条件于 C=c 的问题；本文数字报告事前期望。评价任务先固定为猜一个二元状态，猜对得 1，猜错得 0。

“理想读者”能使用真实联合分布，能免费忽略任何额外信号，也没有解析、注意力或上下文成本。因此 V(M|C) 不会低于 V(∅|C)：允许观察 M 的策略集合包含所有忽略 M 的策略。这只是优化集合包含关系的推导。一个受限模型被更多文字干扰，完全可以在实际实验中变差；那会涉及读者计算、输入位置或成本，不能用本式否认。

前五节比较固定暴露渠道。第七节再单独引入选择器，检查选择行为怎样成为信息渠道。两种问题的观测条件不同，不能把后者的整体收益直接贴成前者的单条用途标签。

## 2. 既有理论提供了什么

[Brooks、Frankel 与 Kamenica 的 Comparisons of Signals](https://benjaminbrooks.net/downloads/bfk_comparisons.pdf)区分单个实验的信息质量与信号之间的联合结构。其 §3、Theorem 1 给出对所有附加信号都保持的比较条件，称为 reveal-or-refine。这里采用的启发很窄：单独比较信息源，通常不能保证加入其他信息后仍保持原顺序。

下述二元构造和 AMS 的研究推论由本次工作单独写出并枚举；不把经典信息论现象宣称为新的数学发现。来源定位与阅读边界见[研究记录](../../research/memory-side-information-study/README.md)。

## 3. 一个严格的价值反转

让 Θ 和 C 是相互独立、均匀的二元变量。再让 E 独立于二者，P(E=1)=1/4。比较两个候选：

```text
X = Θ XOR C
Y = Θ XOR E
```

X 是一个带映射关系的记录；C 是解释这份记录所需的映射键。Y 是一条有 75% 正确率的直接报告。这个解释只是帮助理解变量，实验没有使用自然语言。

在没有 C 时，X 与 Θ 独立，观察 X 后仍只能猜对一半。Y 的正确率为 3/4。提供 C 后，Θ=X XOR C，可以完全恢复；Y 与 C 的组合仍然只能达到 3/4，因为 C 对 Θ、Y 的这条渠道没有增量信息。

| 读者已取得的信息 | 仅该信息的最优正确率 | 再暴露 X | 再暴露 Y | X 的增量 | Y 的增量 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无侧信息 | 1/2 | 1/2 | 3/4 | 0 | 1/4 |
| 映射键 C | 1/2 | 1 | 3/4 | 1/2 | 1/4 |

比较顺序从 Y 优于 X 变成 X 优于 Y。C 自己不能提高猜测正确率，作用却十分具体：它改变了另一份记录能够提供什么。

**命题 1。**对于上述固定任务和渠道，任何保持 X、Y 单一顺序、且忽略侧信息是否可用的排列，无法在两个暴露条件中都选择最优渠道。证明直接来自表中的严格不等式。

这不推出一切 context-free retrieval 都没有实用价值。它反驳的是更强的推断：从一次没有侧信息的测量，就把“哪条记忆更有用”当作可迁移到任意读者状态的固定次序。

### 一个足以保持次序的条件

还可以给出正面的保序条件。对每个正概率的读者状态 c，若存在不依赖真实目标 Θ 的随机转换 K_c，使得下面等式在 P(Θ=θ,C=c)>0 的支持上成立：

```text
P(Y=y | Θ=θ, C=c)
  = Σ_x K_c(y | x) P(X=x | Θ=θ, C=c)，对支持内的 θ 及所有 y 成立
```

则观察 X、C 的读者可以先依 K_c 模拟 Y，再执行任何原本使用 Y、C 的行动策略。它至少能达到后者的收益，所以对这个已固定的侧信息环境，V(X|C)≥V(Y|C)。这是信息渠道退化的标准模拟论证，不是本轮新定理；这里把条件写出，帮助判断何时可以安全复用次序。

这项条件允许 K_c 随读者可观察的 c 改变，但不能偷偷使用 Θ。它也只保证当前建模的侧信息环境，不等于 Brooks 等人讨论的对任意附加信号都稳健的比较。实践中的候选若是同一来源的受控删减，可以尝试验证这样的关系；单凭文本更长、得分更高或历史准确率更好，均没有建立这个条件。

## 4. 两两关系也可能完全一样

把上一节的 X 换成独立均匀噪声 U，保留 Θ、C、E、Y 的分布。两个世界具有相同的 P(Θ,X)、P(Θ,C) 和 P(X,C)；所有单变量边际也相同。但是：

```text
耦合世界：X = Θ XOR C       →  accuracy(Θ | C,X) = 1
独立世界：X = U             →  accuracy(Θ | C,X) = 1/2
```

**命题 2。**只依赖 Θ、C、X 的单变量和二变量边际的诊断，无法区分这两个世界的联合可用性。

证明：其全部可观察输入在两世界相同，输出必然相同；联合最优正确率不同。脚本逐一核对六个一阶／二阶边际，并确认三变量联合分布不相同。

这对 memory research 的启发应保持条件性。一个记忆与查询的相关分数、它与当前文本的相似度，以及当前文本本身的任务相关性，可能不足以描述组合用途。真实 embedding 并非这里的概率边际，不能由此直接判定某个 embedding 模型失败。值得检验的是：被实际选择机制舍弃的关系，是否恰好包含解释这条记录所必需的键。

这一点与 AMS 的[候选竞争研究](../../research/experience-reuse-retrieval-study/README.md)回答不同问题。旧研究已经证明，候选仍保留时也可能被有限返回位置挤出。这里保持候选身份不变，检查读者侧信息如何改变它的价值。两项研究不能互相充作独立验证。

## 5. 信息增加，最优正确率也可能不变

再考虑三个条件于 Θ 相互独立的报告 N1、N2、N3，各有 3/4 概率给出真实状态。先只读 N1，再增加 N2。

两份报告一致的概率为 5/8，此时后验正确概率是 9/10；它们冲突的概率为 3/8，此时两状态各占一半。所以最优准确率为：

```text
(5/8) × (9/10) + (3/8) × (1/2) = 3/4
```

与只读一份相同。然而条件熵从约 0.811278 bits 降至 0.668122 bits，N2 贡献约 0.143156 bits 条件信息。增加第三份报告后，多数表决正确率为：

```text
(3/4)^3 + 3 × (3/4)^2 × (1/4) = 27/32 = 0.84375
```

| 暴露内容 | 最优二元准确率 | H(Θ \| 暴露内容)，bits |
| --- | ---: | ---: |
| 无报告 | 0.5 | 1 |
| N1 | 0.75 | 0.811278 |
| N1、N2，条件独立 | 0.75 | 0.668122 |
| N1、N2、N3，条件独立 | 0.84375 | 0.553594 |
| N1 及其精确复制 | 0.75 | 0.811278 |

数字以[保存结果](../../research/memory-side-information-study/results.json)为准；分数用有理数精确运算，熵用双精度计算并保存十二位小数。

**命题 3。**对于固定行动集合和 0–1 收益，边际正确率收益为零，不足以推出新增证据没有条件信息。上面的独立报告与精确副本对照就是反例。

因此，若一个 memory utility label 只来自本轮答案是否正确，“没有提高分数”至少可能表示三件不同的事：没有新增信息；新增信息改变了后验，却没有提高当前行动问题的最优得分；读者没有使用它。这里并不要求每个观测下的最优行动集合都不变：两份报告冲突时会出现并列最优，而沿用第一份报告的行动仍然最优。这个枚举只把前两种解释严格分开，第三种需要实际读者干预。改用校准概率、另一项收益函数或后续任务，可能看见不同收益；这仍须重新说明研究对象，不能临时挑一项有利指标来挽救结果。

## 6. 对现有 AMS 判断的具体修订

**`relevance-in-context`。**保留其 query／需要相关性论点，在“当前判断与未解处”补上 reader 侧信息及联合结构。一个任务的需求没有变化，记忆的增量用途仍可能因先前已经解决了什么而变化。

**`experience-becomes-policy`。**其逐候选增量用途实验仍是有效的既有观察。本次增加其外推条件：逐条用途标签应被视为对指定 C 和评价损失的标签。复用标签时若隐藏地改变 C 或 loss，便改变了学习目标；不能仅以候选文本相同认定标签稳定。

**`experience-to-capability`。**在竞争解释中加入“证据已经到场，但其互补键不在读者状态中”和“新增信息未跨越行动决策边界”。它们分别指向暴露组合与评价敏感性；都不能由提高 ANN recall 自动解决。

**`representation-and-use` 及其后续分支。**本研究不改写已有 representation receipts。固定视图下的可恢复性、某个读者的利用能力和固定决策问题的价值仍是不同结论。读者侧信息应成为未来比较的显式条件，而非事后解释。

## 7. 把哪条记忆送来，本身也在传递信息

读者收到一条记录，通常也能看见它的身份、位置、排序或来源。选择器可能已经看过读者没见过的工具结果，甚至已经做过一部分判断。于是，读者获得的不只有记录原来写下的内容，还有“在当前条件下，系统选择了它”这一事实。

这与解释模型中的既有问题相通。[Jethani 等人的研究](https://proceedings.mlr.press/v130/jethani21a.html)在 §3.1 分析 selector 与 predictor 联合训练时，预测如何编码进选择 mask；§3.2 进一步说明，选择不同子集可以间接传递未被选中的分支条件。§4 用独立随机选择训练 evaluator，区分这类编码与所选特征的条件预测能力。这里借用问题区分，没有复现其模型或把它的方法直接移植成 memory 系统。

### 7.1 先把整条传递过程写清

令 U 为带身份的候选池，Z 为选择器额外可见的信息，C_R 为读者原有信息。选择策略 π 依据允许的输入与独立随机数 R 产生身份 J，交付正文 P=U[J]。若界面同时显示身份和正文，读者实际观察的是：

```text
J = π(U, Z, R)       P = U[J]
Vπ = E[max_a E[u(a, Θ) | C_R, J, P]]
```

π 的作用包含在联合分布中。本文的理想读者知道这个真实分布；它不是一个未经训练、却神奇懂得任意编码的语言模型。即使所有候选字节和 query 都没变，改变选择器可见的 Z 或策略 π，也可能改变 J、P 对目标的含义。

下面三种设定都只选两条候选中的一条，读者起初没有侧信息（C_R=∅）；第二行的 C 仍指前文的映射键，此处只有选择器能直接看见它。选择器从未直接接收 Θ、噪声变量或评分答案；它只取得表中声明的 Z 或 C。选择规则是事先写明的，不是训练所得。正文、身份与随机控制的完整分布保存在 [selection-results.json](../../research/memory-side-information-study/selection-results.json)，计算沿用本研究的 Bayes evaluator。

| 设定 | 选择器看见什么、怎样选择 | 两条候选的正文 | 只看所选正文 | 看身份与正文 | 独立随机选择后看身份与正文 |
| --- | --- | --- | ---: | ---: | ---: |
| 身份传递报告 | Z 以 3/4 概率等于 Θ；J=Z | 相同常量 | 1/2 | 3/4 | 1/2 |
| 身份与正文互补 | C 与 Θ 独立；J=C | 都是 X=Θ XOR C | 1/2 | 1 | 1/2 |
| 正文也能承担编码 | 同第一行；J=Z | 身份 0 对应正文 0，身份 1 对应正文 1 | 3/4 | 3/4 | 1/2 |

所有格子都是指定分布下的最优 0–1 正确率，不是模型观测。随机控制用独立均匀 R 替换选择依据，保持各身份被选中的边际概率各半、返回条数相同；它改变了选择与当前世界的关联。

### 7.2 没有直接泄露答案，也能传递关键条件

第一行中，两条记录的正文完全相同，固定暴露任意一条都无法帮助判断。选择器把自己取得的带噪报告 Z 编成身份 J，读者便能达到 3/4。若研究目标是整体系统效用，这种传递可以是合法而有益的；若把收益解释成“这段正文保存了有用经历”，便认错了信息来源。

第二行更能说明侧信息的作用。C 独立于 Θ，因此仅看 J=C 的准确率仍是 1/2。两份候选都携带同一个 X，正文单独也只有 1/2。但读者看见 J 和 X 后，可以计算 Θ=X XOR J，准确率变成 1。选择器甚至不需要知道 X，就能通过身份传递解释 X 的键。

在这个设定里，`I(Θ;J)=0`，而 `I(Θ;J | P)=1 bit`。所以“编号单独不能预测答案”不能排除它在完整消息中起作用。它传递的可能是解释正文所需的条件，而非答案标签。这里延续了前文的联合关系问题，没有增加一个独立的自然语言验证。

第三行说明，仅隐藏编号不是通用修复。候选池始终是固定的 `[0,1]`，其中没有当前目标的信息；但依据 Z 选择哪个正文，会让 P 本身等于 Z。删掉 J 后仍然得到 3/4。此时身份与正文提供的是冗余编码，不能因为额外显示 J 没有提高分数，就断言选择过程没传递信息。

### 7.3 “全部记忆”是否真的是完整信息？

三种设定中，只把全部候选交给读者，最优准确率都是 1/2。这不违反信息增加不会降低理想决策值：选择器还看见了候选池之外的 Z 或 C。公平的完整信息参照是 U 加上这些额外观察；其正确率分别为 3/4、1、3/4，与表中的选择消息一致。

一般地，若交付消息只由 U、Z 和独立随机数生成，且双方采用相同先验、读者保留同一 C_R，观察完整 U、Z、C_R 的理想读者可以模拟交付过程，故其最优收益不会更低。这个模拟论证不保证受限语言模型阅读长上下文时也更好；它只确定了信息层面的比较对象。

同样，条件互信息可以描述消息含有什么，却不能自动分配因果功劳：`I(Θ;J,P | C_R)` 可按链式法则展开，而 P 本身由选择产生，不能把其中一项命名为“原记录的独立贡献”。在重复正文的前两行中，隐藏 J 保持 P 不变，便于检查身份渠道；在任意真实候选池中，随机化选择通常还会改变正文内容，需要分别解释这些干预。

### 7.4 对下一次实验的实际改变

今后测量固定记录用途时，暴露安排须独立于该世界的隐藏答案及 selector 私有观察；不能让“本次选中”悄悄成为额外提示。若研究的本来就是自适应选择，则保存 selector 的完整可见输入、选择身份与顺序、reader 的实际消息，并将结论归给这条完整传递过程。

相应的控制也要有针对性：相同正文配不同身份，才能隔离身份作用；只看身份的基线不能替代身份与正文的联合检查；删掉元数据的版本仍须检查正文选择是否传信。候选池全量基线要声明是否包括 selector 的额外信息，不能仅凭“全量”二字认定信息充分。

这也补充了[组合证据研究](memory-evidence-complementarity.md)对“未完整选中支持却答对”的解释：除了猜中、背景知识或支持标注遗漏，还可能是选择器将未交付观察的作用编码进了返回结果。应追查实际渠道，而不是直接宣布支持无用、发现作弊，或把该行计成正文支持完整。原有不透明低阶界的所有世界仍给 selector 相同输入；只要这项前提保持，新增见证不会改变那个界。

## 8. 一个有区分力的后续研究

可以在相同当前问题下，交叉改变“解释键 C 是否在读者上下文中”和“暴露带键记录 X 或直接报告 Y”。先保持 writer、candidate pool、reader 和预算不变，再单独研究候选选择。输入使用新写的公开合成映射表、别名规则或工具版本约定；各世界平衡位置、长度和词面。不给系统世界编号、答案标签或含答案的文件名。

具体输入、权重、交互量与失败条件见[未执行协议](../../research/memory-side-information-study/protocol.md)。第一阶段保持强制二选一并另记概率，让它与上面的 0–1 决策值相接。分别记录组合是否信息充分，以及答案是否正确；信息不足也可能猜中，信息充分也可能被读者用错。先保存实际暴露字节，再以独立的输入充分性审查确定条件。若进一步研究适当暂缓，须另行规定允许 abstain 的行动集合和收益，不能与本阶段准确率混合。

主要观察量为固定读者的任务正确率；校准分数、总 token 和 latency 分列，若进一步统计不受支持的确定回答，要预先固定置信度阈值。最有价值的竞争解释是“互补键帮助恢复内容”与“多一段文字只是提示模型更仔细”。使用等长、同格式但不相关的键作为控制，并在相同世界做单独的解码能力检查。人类可读映射若仍超出模型能力，应报告 bounded reader failure，不能将其混入信息不存在。

这份协议未执行。若有／无 C 的效应不能稳定区分，或普通全上下文基线已足够，便不支持为此引入复杂选择机制。即使模型实验失败，上述三个有限命题仍保持它们的数学边界；不能把理论反例当作工程收益的代替品。

## 9. 继续研究的入口

这里最值得继续的是记忆价值的可迁移条件：哪些关于 reader 状态的充分描述，能让一批用途标签迁移到另一个时点、任务或模型？完全获知 reader 内部状态通常不可行，可以先研究可观察的当前输入、已完成子任务和实际工具输出。若这些仍不足以解释排名反转，就保留未观测状态的边界。

另一个独立问题是价值函数：一条记忆帮助校准不确定性、帮助当下行动、帮助未来提问，可能出现不同次序。应让研究问题决定评价，而不能从现成评分器反推“有用”的含义。

选择渠道又增加了一个具体条件：用途标签究竟属于固定正文、带来源的记录，还是某种 selector 与 reader 的配对？下一步需要检验哪些可观察的策略变化会破坏这种标签迁移，以及在保留有益选择推理时，怎样让人仍能追溯信息来自哪里。本文的精确见证只建立了区分这些对象的必要性，没有证明现实系统经常使用这类编码。
