# AMS 的研究体

从[工作 thesis](programme/thesis.md)和[研究方法](programme/method.md)进入，也可以直接读[一条记录、一种表示、一个记忆系统](entries/records-representations-systems.md)。

`programme/` 保存项目的可修订立场与方法；`entries/` 保存文章 metadata 与一般 Markdown 正文。Metadata 的 `bodyFile` 相对本目录，可指向 programme 中的正文，因此同一文章只有一份可编辑来源。`sources/` 保存单篇来源札记，`inquiries/` 保存持续问题，`transfers/` 保存可选实践判断。

`map.json` 组织领域、长期方向、阅读入口与具体理解变化；分类可交叉或暂缺，不是学习进度。`catalog.json` 维护展示次序、来源 filters 和旧 atlas。新增对象不必先修改 order：未列出的条目会按日期与 ID 稳定追加。

这整个目录是公开研究，不存放私人共学、原始聊天、草稿提示或工作接续。草稿留在 repo 外，完成后按[作者指南](../docs/authoring.md)进入。研究协议、runner 与历史结果继续由 [`research/`](../research/) 中各自的目录维护。
